はじめに

CPG HUB は、退去立会・リノベーション・空室見積・営繕・定期清掃・緊急対応の仕事を、受付から入金まで見るためのアプリです。

仕事の流れ
受付→立会・現地調査→見積→受注→引渡（Access）→完工→請求→入金

現場が終わっても、仕事は終わりではありません。入金されて、はじめて「完了」です。

大事：入力した内容は、その端末（スマホ）の中にだけ残ります。ほかの人のスマホには出ません。前から使っているスマホに「（架空）」と付いた案件があれば、それは練習用の例です（下の「3. 練習用の例を消す」）。

最初の設定

1. 新しい版にする（開き直す）

  1. CPG HUB を開く
  2. 画面を下に引っぱって離す（または、いったん閉じて開き直す）
  3. 左上の CPG HUB の下に出ている版（例：v1.35・10/26更新）を見る。このマニュアルと同じ版になっていればOK

版の文字を押すと、このマニュアルが開きます。

2. Googleとつなぐ

  1. ホームの青いボタン Googleとまとめて同期 を押す
  2. 自分のGoogleアカウントを選ぶ
  3. 「このアプリは Google で確認されていません」と出たら、「詳細」→「CPG HUB（安全ではないページ）に移動」の順に押す（会社で用意したアプリなので、この表示が出るのは普通です）
  4. カレンダーなどの使用を許可する
  5. ボタンの下に ✓ が3つ（Googleにログイン・カレンダー一覧・予定の読み込み）出れば完了です

ログインは、アプリを開くたびに必要です。ログインの情報はスマホに保存しません。前回同期したGoogleの予定はスマホに残るので、開き直してもすぐ見られます（「前回の同期（日時）」と表示）。最新にするときは「Googleとまとめて同期」を押してください。

3. 練習用の例を消す（前から使っているスマホだけ）

新しく使い始めるスマホは、何も入っていない状態から始まります。ホームに「まだ案件がありません」と出たら、右上の ＋ 受付 から始めてください。

前から使っているスマホで、「（架空）」と付いた案件や、左上に「試作・架空データ」の表示があるときは、本番の入力を始める前に消してください。

  1. 下のメニューの 数字 を開く
  2. 「練習用の例（架空）」の 練習用の例（架空）を消す を押す
  3. 「（架空）と付いた案件・ToDo・領収書を消します。自分で入力した内容は消えません」と出たら 消す
  4. 例がなくなると、ボタンと「試作・架空データ」の表示は出なくなります

例をGoogleカレンダーに登録していた場合、カレンダーの予定は残ります。必要ならGoogleカレンダーで消してください。

毎日の使い方

  1. アプリを開いたら、まず Googleとまとめて同期 を押す
  2. 決まり：入力がなくても、1日3回（朝・昼・夕方） Googleとまとめて同期 を押してください。予定の変更やタスクリクエストを受け取り、自分の記録を社長に届けるためです。社長の画面では、今日まだ同期していない人が赤で出ます
  3. ホームのタイルを見る
    • 期限切れのToDo（赤）：今すぐやること
    • 今日までのToDo：今日中にやること
    • 対応中の緊急：受付からの時間が出ます
    • 未入金：請求したのに入金がまだのもの。遅れがあると赤
    • 立替 未提出：まだ経理に出していない領収書
  4. 下のメニューの ToDo を開き、上から順に片付ける。ToDoは案件の段階に合わせて自動で出ます。案件を進めると消えます

案件

受付

  1. 右上の ＋ 受付 を押す
  2. 会社（CP・CPY・AT）の大きいボタンを押して選ぶ（前回選んだ会社が、初めから選ばれています）
  3. 依頼元は候補から選べます：アレップス、オリバー、ハウスコムコミュニケーションズ立川、ハウスコムコミュニケーションズ大和、ミニミニ城西、ミニミニ神奈川、ミニテック立川、その他。候補に無い名前は自由に入力できます
  4. 種類・依頼元・物件・部屋・住所・担当を入れて 受付する
  5. 会社を間違えたときや、前からある案件で「会社未設定」と出ているときは、案件の詳細の「会社」の 直す（または 選ぶ）で選びます。案件一覧の「会社未設定」で、未設定の案件だけを出せます
  6. 受付日時は、はじめは今の日時が入っています。実際に依頼を受けた日時にしてください。前に受けた依頼を後から入力するときは、過去の日時に直します
  7. 受付日時を間違えたときは、案件の詳細の「受付」の横の 直す で直せます。緊急の経過時間・ToDoの期限・ガントも、直した日時で計算し直します
  8. 立会の実施日や見積の提出日などに、受付日より前の日付を入れると「受付日（m/d）より前の日付です。受付日時を直しますか？」と出ます。受付日を直す か このまま を選びます
  9. 受付番号（例：U-0017）が付きます

追加した依頼の種類

  • 空室見積：リノベーションと同じく、現地調査・見積・受注・Access引渡・施工完了・請求へ進みます。
  • 営繕：受付後に見積額と提出日を記録し、「受注して施工へ」で施工中にします。現地調査の完了やAccessの仕事番号は必須にしません。施工完了後に請求を記録します。保留・失注と、請求後の入金確認も利用できます。

立会・現地調査

  1. 案件を開き、予定日を入れて 日程を決める
  2. Googleカレンダーにも入れるときは Googleカレンダーに登録（自動では入りません）
  3. 行ったら、実施した日を入れて 立会を済みにする（種類によって「現地調査」などの名前です）
  4. 退去立会では、箇所ごとに「家主・入居者・要確認」を選び、金額を入れます

緊急対応も受付段階で予定日を入力し、「時（日本時間・24時間）」と「分（日本時間）」を両方選んで「日程を決める」を押せます。未予約の時・分は未選択です。00時00分も選べます。保存前に日付も必ず確認してください。変更も同じ操作です。保存前に「案件へ戻る」と変更は破棄されます。予定を決めても受付のままで、実施済みにはなりません。自動ToDoの期限は予定日、未予約は従来の受付日です。緊急表示は残ります。Googleカレンダーへの自動登録・更新はしません。

見積・受注

  1. 見積書はExcelで作り、金額と提出日を入れて 見積を提出済みにする
  2. 返事が来たら 受注にする／失注にする（理由を選ぶ）／保留にする（次に確認する日を入れる）
  3. 緊急で先に工事するときは 見積を省いて受注へ（緊急）

更新確認：未保存入力を控えて旧タブを閉じ、同じサイトの 版確認URL から開き直し、アプリとマニュアルの版・改訂日を照合します。インストール済み画面も開き直して版を確認し、旧版なら編集・同期を止めてください。このリンク自体は公開や更新完了を保証しません。サイトデータ削除や再インストールは不要です。

受注後の依頼取消（引渡前のみ）

「受注・引渡待ち」で 受注後の依頼を取り消す を押し、受付番号・物件・依頼元・受注日・金額を確認します。理由を入力し 取消を記録する を押します。「やめる」や「案件へ戻る」では記録を変えません。保存確認に失敗した場合は成功表示をせず、再読み込みまで保存・共有を停止します。入力を控えて再読み込みで最新の記録を確認してください。

取消は完了・入金ではありません。元情報、受注日、金額、領収書、手入力ToDo、指示を残し、対象案件の自動ToDoと動いている案件から外します。案件一覧の終了分も表示する設定で「受注後取消済み」と日本時間の取消日時・理由を確認できます。施工中・請求済み・入金済みは対象外です。「数字」の元の受注月の受注件数・受注額には残り、取消を新たな失注実績には加算しません。取消後の再開機能はありません。旧版の共有閲覧では「失注」と表示されるため、日時・理由・予定時刻の閲覧には新版が必要です。旧版のローカル画面では取消案件を「見積提出済に戻す」で再開できてしまいます。取消機能の運用前に全送信端末と開いたままの旧タブを更新し、旧版で編集・同期しないでください。情報シートの「版」「最終同期」は事後情報で、自動拒否や全端末更新の証明ではありません。Googleカレンダーの既存予定は変更しません。

  2. 工事が終わったら 施工完了にする（3日後に「請求書を出す」ToDoが出ます）
  3. 請求したら、請求日・金額・請求先・入金予定日を入れて 請求済みにする

領収書

社長用の設定では「領収書」を開くと「社員の共有領収書」が最初に開きます。自分の領収書を登録・精算するときは「自分の領収書」へ切り替えてください。社員側の初期表示と、アプリ全体の起動画面は変わりません。表示を切り替えている間はその選択を保ち、他の画面からメニューで領収書を開き直すと初期表示に戻ります。

自分の領収書はこの端末で入力した記録です。社員の共有領収書は、既存の社長用・見る人用設定で閲覧できる社員の記録です。「社員の共有記録を読み直す」で取得します。法人カード分は「立替」「精算書」に含まれないため、共有画面で確認してください。共有元の最終同期と、この端末で読み込んだ時刻は別に表示します。未同期の追加分は確認できません。読み込み失敗・前回記録の表示は、削除を意味しません。原本はDriveの既存権限で開き、権限の追加は行いません。

社長用（管理）

社長のアカウントでログインしたときだけ使えます。詳しい手順は 記録を集める設定（data-setup.md） にあります。

社員を追加する

  1. 先に、Google Cloud の「対象」で、その社員をテストユーザーに追加する
  2. CPG HUB の 数字 → 「管理（社長用）」で、氏名とGmailを入れて 社員を追加
  3. その人に共有メールが届きます。「記録シートにつなぐ」をしてもらう
  4. ホームの「会社の動き」で 社員の記録を読み込む を押すと、みんなの様子が見られます（今日まだ同期していない人は赤で出ます。社員は1日3回同期する決まりです。専務はいつも「黒木秀」、同じ名字の人は「黒木祐」のように名の1字を付けて区別します）
  5. 「ToDo」の欄では、社員ごとに 期限切れ（赤）→ 今日 → 今後7日 の順にToDoが出ます。期限切れがある人は名前が赤になります。8日以降と期限なしは件数だけです。「ToDoはまだ届いていません」と出る人は、その人のCPG HUBを v1.29 以降にして「Googleとまとめて同期」を押してもらうと届きます

タスクリクエストを出す

  1. ホームの「会社の動き」で 社員の記録を読み込む を押す
  2. 「ToDo」の欄で、「タスクリクエスト（代表から）」に、その社員への「リクエストの内容」と「期限」を入れて リクエストする
  3. 「○○さんが同期すると届きます。急ぎならLINEでも伝えてください」と出ます。社員が同期するまで届かないので、急ぐときはLINEでも伝えてください
  4. 社員の名前の横に「リクエスト 未完了 ○・期限切れ ○」が出ます。未完了は期限の近い順で、期限切れは赤です。社員が完了にして同期すると「最近7日の完了」に完了日と完了メモが出ます（もう一度「社員の記録を読み込む」を押すと最新になります）
  5. やめたリクエストは 取り消す → 確認で 取り消す。社員の次の同期で、社員のToDoから消えます
  6. 「社員のToDo」には、社員が自分で持っているToDo（案件の自動のToDoと手入力のToDo）が出ます

会社全体を見る（案件・ガント・予定・ToDo）

  1. ホームの「会社の動き」で 社員の記録を読み込む を押す
  2. 読み込んだ社員の案件とToDoが、案件・ガント・ToDo（予定は今日以前が期限の未完了ToDoのみ）と、ホームの数字（期限切れ・今日・緊急・動いている案件・未入金）にも出ます。ホームの数字は会社全体になります
  3. 社員の分には 社員の記録・見るだけ の印が付きます。押すと詳細が見られますが、直したり消したりはできません。直すときは担当の社員に頼んでください
  4. ガントとToDoは、担当で絞り込めます
  5. 数字 の画面（今月の見積提出・受注・失注・決定率・受注額、失注の理由、種類別、未入金）も、社員の案件を含めた会社全体の数字になります。上の 全社／CP／CPY／AT で会社ごとに絞り込め（案件の会社で分け、未設定なら担当者の所属の会社）、「担当別」の表で担当ごとの見積提出・受注・受注額・未入金が見られます。画面の上に「社員の記録（月/日 時:分 読み込み）を含めた会社全体の数字です」と出ます。「社員の記録はまだ読み込んでいません」と出ているときは、この端末で入力した分だけの数字なので、「Googleとまとめて同期」を押してください。GMの端末では、数字はGMを務める会社の分だけで、会社の絞り込みはその会社に固定です（「会社の動き」の絞り込みも同じで、GMの会社に固定です。全社の役割の人は、社長と同じく全社から選べます）
  6. 「会社の動き」の CP／CPY／AT で、会社ごとに絞り込めます。案件は案件の「会社」で分けます（会社が未設定の古い案件は、担当者の所属の会社で分けます）。同期の状況は、いつも全員分が出ます
  7. 社員がHUBからGoogleカレンダーに入れた予定は、Googleの予定として表示します。案件の進捗印は足しません。社員のToDoも、期限が今日以前のものだけ今日の欄にも出ます
  8. 最後に読み込んだ内容はこの端末に残り、アプリを開き直しても「前回の読み込み（月/日 時:分）の内容です」と出て、そのまま見られます（30日まで。ログイン情報は残しません）。最新にするときは Googleとまとめて同期 を押すと、カレンダーに続けて社員の記録も読み込みます（結果に「社員の記録：○人・案件○件」の行が出ます）
  9. 社員の同期が古いと、古いままの内容が出ます（「同期の状況」で最終同期を確かめてください）。v1.29 以前で同期した社員の案件は、見積提出・保留などの日付が届いていないので、ガントの帯が一部だけになります

会社・役割（全社・GM）を決める

  1. 数字 → 「管理（社長用）」で、社員を追加するときに「会社（複数可）」「役割」「GMを務める会社」を選ぶ。あとから変えるときは、その人の 会社・役割 → 選んで 保存する
  2. 役割：社員＝自分の記録だけ。GM＝GMを務める会社の社員の記録を見る。全社＝全員の記録を見る（例：専務）。全社の人がある会社のGMも務めるときは、役割を「全社」にして「GMを務める会社」を選びます（見る範囲は全社が優先です）
  3. GMは各社1人です。同じ会社に2人目を選ぶと「○○のGMはすでに○○さんです。入れ替えますか？」と出ます。入れ替える を押すと、前の人はGMから外れ（役割がGMなら「社員」に戻ります）、その閲覧の共有も外れます
  4. 保存すると、見る人に、見てよい社員のシートを 閲覧者 で共有します。役割を外したり会社を変えたりすると、その分の閲覧の共有を外します（本人の編集者の共有は変えません）
  5. 見る人がいると「見る人用のリンク」が出ます。リンクをコピー して、見る人に送ってください（LINEなど）

2台目の端末で使う（スマホとPCなど）

  1. 2台目の端末でも、社長のアカウントでログインして 数字 → 管理をはじめる
  2. 1台目で作ったフォルダ「CPG HUB データ」と「CPG HUB_社員一覧」を見つけて使います。「既存の管理データを読み込みました（社員○人）」と出ればOK。新しいフォルダは作りません
  3. 「同じ名前のフォルダが○つあります」と出たときは、一番古いフォルダを使っています。社長のドライブで中身を確かめてください
  4. ほかの端末で社員を追加したり共有を外したりしたあとは、一覧を読み直す を押すと、この端末の一覧も最新になります（「社員の記録を読み込む」のときにも読み直します）
  5. 同じGmailの社員がもう一覧にあるときは、追加できません（「○○さんはすでに追加されています」と出ます）

共有を外す（退職のときなど）

  1. 「管理（社長用）」の一覧で、その人の 共有を外す → 確認で 共有を外す
  2. シートは消えずに、社長のドライブに残ります

会社の動きを見る人用（全社・GM）

社長から役割を「全社」か「GM」にしてもらった人だけが使えます。見るだけで、直したりタスクリクエストを出したりはできません。

  1. 社長から届いた「見る人用のリンク」をコピーする
  2. CPG HUB の 数字 → 「会社の動きを見る（管理者用）」に貼り付けて つなぐ（Googleの画面が出たら許可）
  3. ホームに「会社の動き（見るだけ）」が出ます。社員の記録を読み込む を押すと、見てよい社員の同期の状況・案件・ToDo・未入金・立替が出ます。上のボタンで会社ごとに絞り込めます
  4. 読み込んだあとは、案件・ガント・ToDo の画面にも「社員の記録・見るだけ」で出ます（予定には今日以前が期限の未完了ToDoのみ）。最後に読み込んだ内容は端末に残り、開き直しても見られます（30日まで）。最新にするときは Googleとまとめて同期 を押してください。役割や共有が外れると、残した内容は消えます
  5. GMは、自分の会社の社員の分だけが出ます（ほかの会社のシートは共有されていないので出ません）
