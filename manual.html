はじめに

CPG HUB は、退去立会・リノベーション・定期清掃・緊急対応の仕事を、受付から入金まで見るためのアプリです。

仕事の流れ
受付→立会・現地調査→見積→受注→引渡（Access）→完工→請求→入金

現場が終わっても、仕事は終わりではありません。入金されて、はじめて「完了」です。

大事：入力した内容は、その端末（スマホ）の中にだけ残ります。ほかの人のスマホには出ません。前から使っているスマホに「（架空）」と付いた案件があれば、それは練習用の例です（下の「3. 練習用の例を消す」）。

最初の設定

1. 新しい版にする（開き直す）

  1. CPG HUB を開く
  2. 画面を下に引っぱって離す（または、いったん閉じて開き直す）
  3. 左上の CPG HUB の下に出ている版（例：v1.31・10/24更新）を見る。このマニュアルと同じ版になっていればOK

版の文字を押すと、このマニュアルが開きます。

2. Googleとつなぐ

  1. ホームの青いボタン Googleとまとめて同期 を押す
  2. 自分のGoogleアカウントを選ぶ
  3. 「このアプリは Google で確認されていません」と出たら、「詳細」→「CPG HUB（安全ではないページ）に移動」の順に押す（会社で用意したアプリなので、この表示が出るのは普通です）
  4. カレンダーなどの使用を許可する
  5. ボタンの下に ✓ が3つ（Googleにログイン・カレンダー一覧・予定の読み込み）出れば完了です

ログインは、アプリを開くたびに必要です。ログインの情報はスマホに保存しません。前回同期したGoogleの予定はスマホに残るので、開き直してもすぐ見られます（「前回の同期（日時）」と表示）。最新にするときは「Googleとまとめて同期」を押してください。

3. 練習用の例を消す（前から使っているスマホだけ）

新しく使い始めるスマホは、何も入っていない状態から始まります。ホームに「まだ案件がありません」と出たら、右上の ＋ 受付 から始めてください。

前から使っているスマホで、「（架空）」と付いた案件や、左上に「試作・架空データ」の表示があるときは、本番の入力を始める前に消してください。

  1. 下のメニューの 数字 を開く
  2. 「練習用の例（架空）」の 練習用の例（架空）を消す を押す
  3. 「（架空）と付いた案件・ToDo・領収書を消します。自分で入力した内容は消えません」と出たら 消す
  4. 例がなくなると、ボタンと「試作・架空データ」の表示は出なくなります

例をGoogleカレンダーに登録していた場合、カレンダーの予定は残ります。必要ならGoogleカレンダーで消してください。

毎日の使い方

  1. アプリを開いたら、まず Googleとまとめて同期 を押す
  2. ホームのタイルを見る
    • 期限切れのToDo（赤）：今すぐやること
    • 今日までのToDo：今日中にやること
    • 対応中の緊急：受付からの時間が出ます
    • 未入金：請求したのに入金がまだのもの。遅れがあると赤
    • 立替 未提出：まだ経理に出していない領収書
  3. 下のメニューの ToDo を開き、上から順に片付ける。ToDoは案件の段階に合わせて自動で出ます。案件を進めると消えます

案件

受付

  1. 右上の ＋ 受付 を押す
  2. 種類・依頼元・物件・部屋・住所・担当を入れて 受付する
  3. 受付番号（例：U-0017）が付きます

立会・現地調査

  1. 案件を開き、予定日を入れて 日程を決める
  2. Googleカレンダーにも入れるときは Googleカレンダーに登録（自動では入りません）
  3. 行ったら、実施した日を入れて 立会を済みにする（種類によって「現地調査」などの名前です）
  4. 退去立会では、箇所ごとに「家主・入居者・要確認」を選び、金額を入れます

見積・受注

  1. 見積書はExcelで作り、金額と提出日を入れて 見積を提出済みにする
  2. 返事が来たら 受注にする／失注にする（理由を選ぶ）／保留にする（次に確認する日を入れる）
  3. 緊急で先に工事するときは 見積を省いて受注へ（緊急）

引渡・完工・請求・入金

  1. Accessで現場管理表を作り、仕事番号を入れて 引渡済にする
  2. 工事が終わったら 施工完了にする（3日後に「請求書を出す」ToDoが出ます）
  3. 請求したら、請求日・金額・請求先・入金予定日を入れて 請求済みにする
  4. 入金があったら 入金を記録。全額になると「入金済み（完了）」

「失注」と「削除」の使い分け

こんなとき使うもの
依頼が無くなった・他社に決まった失注にする（記録が残り、数字に入ります）
間違えて登録した・同じ案件を2つ作った案件の一番下の この案件を削除（元に戻せません）
  • Googleカレンダーに登録した案件は、「Googleカレンダーの予定も削除する」にチェックが入っています。ログインしていないときは、先に Googleとまとめて同期 を押してください
  • 領収書が紐づいた案件は削除できません。先に領収書の「案件」を「選ばない」にしてください
  • 消した受付番号は、二度と使いません

予定とカレンダー

  • 下のメニューの 予定 で、月・週・日を切り替えられます。日付を押すと、その日の予定が出ます
  • 画面を横にスワイプすると、前後へ移れます（日表示は1日、週表示は1週、月表示は1か月）。左へスワイプで次、右へスワイプで前です
  • 土曜は青、日曜と祝日は赤です。土日祝の立会は赤いラベルで目立たせています
  • Googleの予定は、カレンダーごとに色と小さなラベル（「CPG HUB」「黒木」など）が付きます
決まり：案件の予定は HUB から、それ以外の予定は Googleカレンダーから入れる。
同じ予定を両方に入れないでください（二重になります）。
  1. HUBで予定日を変えたら、案件の画面で カレンダーの予定を更新 を押す（自動では変わりません）
  2. ほかの人の「非公開」の予定は、中身が出ずに「予定あり」とだけ出ます

入金

  • ホームの 未入金 を押すと、入金待ちだけが遅れの長い順に出ます
  • 入金予定日を過ぎると、毎日「入金を確認する（○日遅れ）」のToDoが赤で出ます

経理に確認を頼む

  1. 入金待ちの一覧（または「数字」画面）で 経理に入金確認を依頼
  2. 文面を見て LINE・メールで送る（送れないときは「コピー」して貼り、送ったので記録する）
  3. 3日たっても返事が記録されないと、「経理の返事を確認する」ToDoが出ます

経理から連絡が来たら

  1. 案件を開き、入金日・入金額を入れる
  2. 「だれからの情報か」で 経理連絡 を選んで 入金を記録
  3. まだ入金が無いという返事なら 経理から返事あり（まだ入金なし）

領収書

立替の登録

  1. 下のメニューの 領収書 → ＋ 領収書を登録
  2. 写真を撮る・選ぶ で領収書を撮る（何枚でも）
  3. 日付・金額・支払先・内容・会社（CP／CPY／AT）・区分を入れる。案件を選ぶと、現場と仕事番号が自動で入ります
  4. 保存する

精算書を作って送る

  1. 「立替」の画面で、会社ごとに 全部で精算書を作る（または、選んで 選んだ分で精算書を作る）
  2. 「精算書」の画面で Excelと写真を送る → LINEやメールで経理（CP・CPYは桜田さん、ATは大須さん）に送る
  3. 経理から精算されたら 精算済にする
領収書の原本は、今までどおり経理に渡してください。写真はスマホの中にだけあるので、たまったら早めに精算書を出してください。
  • 精算日のお知らせ：CP（本社）は火曜、CPY（横浜）は木曜が精算日です。前の日に未提出があると、ホームとToDoでお知らせします（「領収書」→「設定」で変えられます）
  • 差戻し：経理から差し戻されたら、「精算書」の内訳で 差戻し を押す → 直して保存 → もう一度精算書を作る（新しい番号になります）。直した内容は履歴に残ります
  • 「領収書」→「設定」で氏名を入れておいてください。精算書に入ります
  • 法人カードは、「設定」で「法人カードを使う」をONにした人だけに出ます

記録シートにつなぐ（社員用）

社長から「CPG HUBの記録用です。…」という共有メールが届いたら、一度だけ次をしてください。

  1. メールの中のシートのリンクをコピーする
  2. CPG HUB の 数字 → いちばん下の「記録シート（社員用）」に貼り付ける
  3. つなぐ を押し、Googleの画面で許可する
  4. あとは Googleとまとめて同期 のたびに、案件・入金・立替・ToDoの要点と領収書の写真の控えが送られます（メモや住所の細かいところは送りません）

タスクリクエスト（社員用）

  1. 代表からタスクリクエストが来ると、次の Googleとまとめて同期 で届きます。ホームに「タスクリクエスト ○件」と出て、ToDoには リクエスト の印が付きます（期限切れは赤）
  2. 済んだら、そのToDoの 完了 を押す。必要なら「完了メモ」に一言書いて 完了にする
  3. もう一度 Googleとまとめて同期 を押すと、社長の画面に「完了」とメモが届きます。同期するまでは社長に届きません
  4. 代表が取り消したリクエストは、次の同期でToDoから消えます

困ったとき

こんなときこうする
版が古いまま画面を下に引っぱって離す。だめならアプリを閉じて開き直す
Googleの予定が出ない・「カレンダー未接続」と出るGoogleとまとめて同期 を押す。× が出た行の理由を見る
「このアプリは確認されていません」「詳細」→「移動」で進む。進めないときは社長に連絡（登録が必要です）
「ポップアップを許可してください」ブラウザの設定でポップアップを許可して、もう一度押す
案件の日付を変えたのにカレンダーが古い案件の画面で カレンダーの予定を更新
案件を削除できない領収書が紐づいていないか確かめる。依頼が無くなっただけなら「失注」
「保存できませんでした」スマホの空き容量を増やす。たまった領収書は精算書にして送る
精算書を送れない「コピー」やファイルの保存を使い、自分でLINEやメールに付けて送る
記録シートに「権限がありません」自分あてに届いたメールのリンクか確かめる
入力した内容が消えた別のスマホやブラウザで開いていないか確かめる（内容はその端末にだけ残ります）
「（架空）」の案件や「試作・架空データ」の表示が残っている数字 の 練習用の例（架空）を消す（自分で入れた内容は消えません）

社長用（管理）

社長のアカウントでログインしたときだけ使えます。詳しい手順は 記録を集める設定（data-setup.md） にあります。

社員を追加する

  1. 先に、Google Cloud の「対象」で、その社員をテストユーザーに追加する
  2. CPG HUB の 数字 → 「管理（社長用）」で、氏名とGmailを入れて 社員を追加
  3. その人に共有メールが届きます。「記録シートにつなぐ」をしてもらう
  4. ホームの「会社の動き」で 社員の記録を読み込む を押すと、みんなの様子が見られます（3日以上同期していない人には注意が出ます）
  5. 「ToDo」の欄では、社員ごとに 期限切れ（赤）→ 今日 → 今後7日 の順にToDoが出ます。期限切れがある人は名前が赤になります。8日以降と期限なしは件数だけです。「ToDoはまだ届いていません」と出る人は、その人のCPG HUBを v1.29 以降にして「Googleとまとめて同期」を押してもらうと届きます

タスクリクエストを出す

  1. ホームの「会社の動き」で 社員の記録を読み込む を押す
  2. 「ToDo」の欄で、「タスクリクエスト（代表から）」に、その社員への「リクエストの内容」と「期限」を入れて リクエストする
  3. 「○○さんが同期すると届きます。急ぎならLINEでも伝えてください」と出ます。社員が同期するまで届かないので、急ぐときはLINEでも伝えてください
  4. 社員の名前の横に「リクエスト 未完了 ○・期限切れ ○」が出ます。未完了は期限の近い順で、期限切れは赤です。社員が完了にして同期すると「最近7日の完了」に完了日と完了メモが出ます（もう一度「社員の記録を読み込む」を押すと最新になります）
  5. やめたリクエストは 取り消す → 確認で 取り消す。社員の次の同期で、社員のToDoから消えます
  6. 「社員のToDo」には、社員が自分で持っているToDo（案件の自動のToDoと手入力のToDo）が出ます

会社全体を見る（案件・ガント・予定・ToDo）

  1. ホームの「会社の動き」で 社員の記録を読み込む を押す
  2. 読み込んだ社員の案件とToDoが、案件・ガント・予定・ToDo の画面と、ホームの数字（期限切れ・今日・緊急・動いている案件・未入金）にも出ます。ホームの数字は会社全体になります
  3. 社員の分には 社員の記録・見るだけ の印が付きます。押すと詳細が見られますが、直したり消したりはできません。直すときは担当の社員に頼んでください
  4. ガントとToDoは、担当で絞り込めます
  5. 社員がHUBからGoogleカレンダーに入れた予定は、案件の予定として1回だけ出ます（二重に出ません）
  6. 読み込んだ内容は、端末には残りません。アプリを開き直すと消えるので、もう一度 社員の記録を読み込む を押してください（前回の読み込み日時が出ます）
  7. 社員の同期が古いと、古いままの内容が出ます（「同期の状況」で最終同期を確かめてください）。v1.29 以前で同期した社員の案件は、見積提出・保留などの日付が届いていないので、ガントの帯が一部だけになります

会社・役割（全社・GM）を決める

  1. 数字 → 「管理（社長用）」で、社員を追加するときに「会社（複数可）」「役割」「GMを務める会社」を選ぶ。あとから変えるときは、その人の 会社・役割 → 選んで 保存する
  2. 役割：社員＝自分の記録だけ。GM＝GMを務める会社の社員の記録を見る。全社＝全員の記録を見る（例：専務）。全社の人がある会社のGMも務めるときは、役割を「全社」にして「GMを務める会社」を選びます（見る範囲は全社が優先です）
  3. GMは各社1人です。同じ会社に2人目を選ぶと「○○のGMはすでに○○さんです。入れ替えますか？」と出ます。入れ替える を押すと、前の人はGMから外れ（役割がGMなら「社員」に戻ります）、その閲覧の共有も外れます
  4. 保存すると、見る人に、見てよい社員のシートを 閲覧者 で共有します。役割を外したり会社を変えたりすると、その分の閲覧の共有を外します（本人の編集者の共有は変えません）
  5. 見る人がいると「見る人用のリンク」が出ます。リンクをコピー して、見る人に送ってください（LINEなど）

2台目の端末で使う（スマホとPCなど）

  1. 2台目の端末でも、社長のアカウントでログインして 数字 → 管理をはじめる
  2. 1台目で作ったフォルダ「CPG HUB データ」と「CPG HUB_社員一覧」を見つけて使います。「既存の管理データを読み込みました（社員○人）」と出ればOK。新しいフォルダは作りません
  3. 「同じ名前のフォルダが○つあります」と出たときは、一番古いフォルダを使っています。社長のドライブで中身を確かめてください
  4. ほかの端末で社員を追加したり共有を外したりしたあとは、一覧を読み直す を押すと、この端末の一覧も最新になります（「社員の記録を読み込む」のときにも読み直します）
  5. 同じGmailの社員がもう一覧にあるときは、追加できません（「○○さんはすでに追加されています」と出ます）

共有を外す（退職のときなど）

  1. 「管理（社長用）」の一覧で、その人の 共有を外す → 確認で 共有を外す
  2. シートは消えずに、社長のドライブに残ります

会社の動きを見る人用（全社・GM）

社長から役割を「全社」か「GM」にしてもらった人だけが使えます。見るだけで、直したりタスクリクエストを出したりはできません。

  1. 社長から届いた「見る人用のリンク」をコピーする
  2. CPG HUB の 数字 → 「会社の動きを見る（管理者用）」に貼り付けて つなぐ（Googleの画面が出たら許可）
  3. ホームに「会社の動き（見るだけ）」が出ます。社員の記録を読み込む を押すと、見てよい社員の同期の状況・案件・ToDo・未入金・立替が出ます。上のボタンで会社ごとに絞り込めます
  4. 読み込んだあとは、案件・ガント・予定・ToDo の画面にも「社員の記録・見るだけ」で出ます。端末には残らないので、開き直したら読み込み直してください
  5. GMは、自分の会社の社員の分だけが出ます（ほかの会社のシートは共有されていないので出ません）
