# v1.47.5 数字の集計検証

基準 main: `1df58840bb19d3437a2c1141f83a275ea97c7509`（v1.47.4）。

- 通常失注は `stage === lost && !cancelledAt`。受注日が残っていても受注件数・額から除外。
- 受注後取消（cancelledAtあり）は従来の元受注実績を保持し、通常失注へ混ぜない。取消表示・履歴・ToDo除外は変更なし。
- 通常失注の失注日が今月なら月内、空欄なら月不明として件数を明示し、担当／種類／理由に同じ集合を用いる。過去月・未来月は除外。決定率は日付のある今月分のみ。日付を推定しない。
- 種類別・担当別の見積提出は同じ今月のestSentDateで集計。
- 受注日と失注日の併記、失注段階に受注日が残る場合はローカル／共有閲覧の案件画面に注意。保存を止めず、元データを書き換えない。
