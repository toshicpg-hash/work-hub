# CPG HUB に Googleカレンダーの予定を出す設定のしかた

CPG HUB の「予定」画面に、Googleカレンダーの予定を出すための手順です。
読むカレンダーは次の2つです。

- 「CPG」共有カレンダー
- 黒木専務のカレンダー

HUB はカレンダーを**読むだけ**です。HUB からカレンダーに予定を書き込むことはありません。
予定の「説明（メモ）」欄も HUB には送りません。送るのは、件名・日時・場所・どのカレンダーか、だけです。

全部で30分くらいかかります。パソコンで作業してください。

---

## 0. 用意するもの

- 社長の Google アカウントでログインしたパソコン
- このリポジトリの `gas/calendar-feed.gs` の中身（あとでコピーして貼り付けます）

---

## 1. 専務のカレンダーを社長に共有してもらう（専務にお願いする作業）

社長のアカウントから専務のカレンダーを読めるようにします。**専務のパソコン**で、専務にやってもらいます。

1. 専務の Google アカウントで Googleカレンダー（calendar.google.com）を開く
2. 左の「マイカレンダー」で、自分のカレンダーの名前にマウスを当て、「︙」→「設定と共有」を押す
3. 「特定のユーザーまたはグループと共有する」で「ユーザーやグループを追加」を押す
4. 社長のメールアドレスを入れる
5. 権限は **「予定の表示（すべての予定の詳細）」** を選ぶ
   （「予定の表示（時間枠のみ、詳細は非表示）」だと件名が出ません。これより下の権限は選ばないでください）
6. 「送信」を押す
7. 社長のメールに届いた案内のリンクを開いて、カレンダーを追加する

「CPG」共有カレンダーがまだ社長のカレンダー一覧に出ていない場合は、同じようにして共有してもらってください。

---

## 2. カレンダーID を調べる（社長の作業）

カレンダーには、それぞれ住所のような「カレンダーID」があります。

1. 社長のアカウントで Googleカレンダーを開く
2. 左の一覧で「CPG」にマウスを当て、「︙」→「設定と共有」を押す
3. 下のほうの「カレンダーの統合」にある **「カレンダー ID」** をコピーして、メモ帳に貼っておく
   （例：`xxxxxxxx@group.calendar.google.com` のような形です）
4. 専務のカレンダーでも同じことをする（専務のカレンダーIDは、専務のメールアドレスと同じことが多いです）

---

## 3. Apps Script（アップス・スクリプト）にコードを貼る

1. ブラウザで **script.google.com** を開く（社長のアカウントで）
2. 左上の「新しいプロジェクト」を押す
3. 左上の「無題のプロジェクト」を押して、名前を「CPG HUB カレンダー」にする
4. 最初から入っている `function myFunction() { … }` を全部消す
5. `gas/calendar-feed.gs` の中身を全部コピーして、貼り付ける
6. 上の「💾（プロジェクトを保存）」を押す

### タイムゾーンを日本にする

1. 左の「⚙（プロジェクトの設定）」を押す
2. 「タイムゾーン」を **「(GMT+09:00) 日本標準時 - 東京」** にする

---

## 4. スクリプト プロパティ（設定値）を入れる

カレンダーIDと合言葉（キー）は、コードには書かず、ここに入れます。

1. 「⚙（プロジェクトの設定）」の画面を下に進み、「スクリプト プロパティ」の「スクリプト プロパティを追加」を押す
2. 次の2つ（できれば3つ）を入れて「スクリプト プロパティを保存」を押す

| プロパティ | 値 | 例 |
|---|---|---|
| `CAL_IDS` | 2. で調べたカレンダーIDを、**カンマ（,）でつないだもの** | `xxxxxxxx@group.calendar.google.com,yyyy@example.com` |
| `FEED_KEY` | 合言葉。**20文字以上**の、人に推測されない文字列 | 英数字をでたらめに並べたもの |
| `CAL_NAMES`（なくてもよい） | HUB に出す短い名前。`CAL_IDS` と**同じ順番**でカンマでつなぐ | `CPG,黒木` |

- `FEED_KEY` は、パスワード作成ツールなどで作ると安心です。誕生日や電話番号は使わないでください。
- `CAL_NAMES` を入れないと、カレンダーの名前の最初の4文字がラベルになります。

### 読めるか確かめる

1. 上の「エディタ（< >）」に戻る
2. 上の関数の選び欄で **`checkSetup`** を選び、「実行」を押す
3. はじめての実行では「承認が必要です」と出ます。5. の「許可のしかた」と同じように許可してください
4. 下の「実行ログ」に、カレンダーごとに「読めます: CPG」のように出れば OK です
   「読めません」と出たら、カレンダーIDの間違いか、1. の共有がまだです

---

## 5. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」を押す
2. 「種類の選択」の ⚙ を押して **「ウェブアプリ」** を選ぶ
3. 次のように入れる
   - 説明：`CPG HUB カレンダー`
   - 次のユーザーとして実行：**自分（社長のメールアドレス）**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押す

「全員」にしても、合言葉（`FEED_KEY`）を知らない人には予定は見えません。

### 許可のしかた

1. 「アクセスを承認」を押し、社長のアカウントを選ぶ
2. 「このアプリは Google で確認されていません」と出たら、左下の「詳細」→「CPG HUB カレンダー（安全ではないページ）に移動」を押す
   （自分で作ったスクリプトなので、この表示が出るのは普通です）
3. 「カレンダーの表示」などの内容を確かめて「許可」を押す

### URL を控える

デプロイが終わると **「ウェブアプリ」の URL** が出ます。
`https://script.google.com/macros/s/……/exec` という形です。これをコピーしてメモ帳に貼っておきます。

---

## 6. CPG HUB に URL と合言葉を入れる（使う人の端末ごと）

1. CPG HUB を開き、下のメニューの **「数字」** を押す
2. いちばん下の **「Googleカレンダー連携」** に入れる
   - 公開URL：5. で控えた URL
   - キー：4. で決めた `FEED_KEY`
3. **「接続テスト」** を押す
   - 「接続できました。今日から7日間の予定 ○件（カレンダー：CPG・黒木）」と出れば成功
   - 「キーが違います」→ 合言葉の打ち間違い
   - 「通信できませんでした」→ URL の間違い、またはネットにつながっていない
4. **「保存する」** を押す
5. 下のメニューの「予定」を開くと、Googleカレンダーの予定が色付きのラベル（「CPG」「黒木」）で出ます

**大事：** この設定は端末ごとです。社長のスマホ、専務のスマホなど、HUB を使う端末それぞれで 6. を行ってください。

---

## 困ったとき

- **予定画面に「カレンダー未接続」と出る**
  6. の設定がされていないか、接続に失敗しています。「数字」画面の「接続テスト」で原因を確かめてください。この間も、HUB の案件の予定はいつもどおり表示されます。
- **Googleカレンダーで予定を直したのに HUB に出ない**
  HUB は読み込んだ予定を5分間おぼえています。5分ほど待つか、HUB を開き直してください。
- **合言葉が他の人にもれたかもしれない**
  4. の `FEED_KEY` を新しいものに変えて保存し、各端末の 6. の「キー」も新しいものに入れ替えてください。古い合言葉はすぐに使えなくなります。
- **`gas/calendar-feed.gs` が新しくなったとき**
  コードを貼り替えて保存したあと、「デプロイ」→「デプロイを管理」→ ✏（編集）→ バージョンで「新バージョン」を選んで「デプロイ」を押します。こうすると URL は変わりません。
- **連携をやめたい**
  HUB の「Googleカレンダー連携」で URL とキーを消して「保存する」を押します。Apps Script 側も止めるときは、「デプロイを管理」でデプロイを「アーカイブ」します。
