# CPG HUB 開発引継ぎ

更新日：2026-11-07 JST。対象：`toshicpg-hash/work-hub` のみ。

## 担当と運用ルール

- 前回のトシ了承の例外分担：PR-A（管理者の指示箱）はエジソン／クロ、PR-B（社員の受信・完了報告）はコーディー／ナミ。互いの領域は編集せず、他担当へ直接指示しない。PR-B以外の開発停止は解除しない。
- 原則CPGの実装担当は同時に1人（今回のみ上記の分担例外）。担当切替を決めるのはトシのみ。他の担当へ独自に実装を依頼しない。
- 作業開始時に最新main、remote、既存PRと作業中の変更を確認する。競合する書込みを見つけたらbranch・commit・ファイルを記録して確認する。
- この文書を進捗・制限・引継ぎに合わせて更新する。各版でREADMEとmanualの版・改訂履歴を整合させる。
- PRのmerge・公開にはトシの明示承認が必要。GitHub保存・Draft PR作成の承認と混同しない。
- 実案件・Googleデータ・共有権限・カレンダー・第三者送信は、コード修正の承認に含めない。合成データ／ローカル／通信モックで検証する。

## v1.50.5 社員の記録の読み込み：やり直しと理由

## v1.50.0 予定の共有ボタン・役割「経理」「業務管理」
