# 領収書の案件・区分・入力履歴（v1.43）

会社用CPG HUBの領収書入力だけを改善します。PAPA HUBは変更しません。

## 案件を選ぶ

「この端末の案件」に加え、案件一覧で閲覧できる読み込み済みの共有案件を選べます。共有案件の候補には社員名・会社・受付番号・物件と部屋・仕事番号を表示します。候補表示のためのGoogleへの追加取得は行いません。

共有案件は読み込み元のシートIDと元の案件IDの組み合わせで識別します。社員間で受付番号が同じ場合や、社員名が変わる場合も、名前だけで参照先を決めません。同一の読み込み元に矛盾する同じ受付番号がある場合は、その候補を選ばず確認を必要とします。

案件を選ぶと、その時点の現場・部屋・仕事番号を領収書側へ転記します。会社・金額・日付・支払い方法は変更しません。共有元の案件は変更せず、領収書への参照と転記内容だけを保存します。転記後も領収書側で自由に修正できます。

「選ばない」に戻すと案件との関連だけを外し、入力済みの現場・部屋・仕事番号は残します。案件を選ばずに手入力もできます。編集時に元の案件が現在の候補にない場合は、保存済みの関連を表示して保持し、同じ番号の別案件へ自動で付け替えません。

既存の領収書の `site` 表記は変更・分解しません。新しい部屋入力は任意の `room` として保存し、一覧・Excel・既存の立替出力では現場と部屋を合わせて表示します。共有案件の参照情報は領収書の `caseRef` に保存し、`caseId` は元シートとの組み合わせを表すキーです。Excelでは元の受付番号・社員名・会社を読める形で表示し、読み込み元シートのIDを出力しません。端末内案件の従来のIDはそのままです。

## 区分

材料費・駐車場代・交通費・消耗品・その他を残し、会議費・接待交際費を追加します。役職による制限はありません。高速道路代・宿泊費・燃料費などは新しい固定候補に追加しません。既存の独自区分が保存されている場合は、編集時にその値を保持します。

これは入力用の区分です。会計科目の自動確定・推測・書き換えは行いません。

## 支払先・内容の履歴候補

この端末に保存済みの自分の領収書だけから、候補を最大5件ずつ表示します。社員の共有領収書、Google Drive、別のシートから候補用データを取得しません。

支払先は最近保存・使用したものを優先し、同じ名称の表記の重複をまとめます。入力文字で絞り込み、候補をタップして入力できます。新しい名称も自由入力できます。

内容は入力中の支払先で使った履歴を優先し、足りない場合はこの端末の他の履歴を表示します。同じ内容は重複表示せず、文字で絞り込めます。候補をタップした後も自由に修正できます。

候補をタップするだけでは保存しません。支払先・内容以外の金額・日付・会社・案件・部屋・仕事番号・区分・支払い方法は変更しません。キャンセルした入力は履歴候補に追加しません。保存に成功した領収書の更新時刻を新しさの判定に使い、領収書の日付は変更しません。

## 保存・検証

v1.42のPDF・画像の選択、原本保存、読み戻し確認、二重登録防止、失敗時の入力保持、PDF閲覧・書き出しを保持します。既存の領収書、添付、金額、案件との関連、編集履歴、同期設定を一括置換・初期化する処理は追加しません。

`tests/receipt-input.test.cjs` と `tests/receipt-input-browser.cjs` は合成データ専用です。同じ案件ID、参照元が変わる場合、候補なし、履歴の並び順・重複・絞り込み、タップと自由修正、新規登録・編集・キャンセル・再読込、元データ保持、PDFとの組み合わせ、共有領収書を参照しないことを確認します。スマホ幅320/390/822pxのChromiumで確認します。実機の操作・実データの変更・本番Googleへの書き込みは行いません。
