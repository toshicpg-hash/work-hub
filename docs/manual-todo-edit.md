# 手入力ToDoの編集（v1.36候補）

会社用CPG HUBの、この端末で登録した手入力ToDoが対象です。社員の「見るだけ」の記録、Google予定、案件から自動で作るToDo、タスクリクエストは対象外です。担当名は編集権限ではありません。

## 使い方

1. ほかのCPG HUB画面を閉じ、公開後の最新版を開きます。同期中は終了を待ちます。
2. 「ToDo」で対象の「編集」を押します。完了済みは「完了した手入力ToDo（全期間）」から開けます。
3. 必要に応じて「編集前の控えを保存」を押し、ファイルを安全な場所に保存します。
4. 内容、期限・次の確認日、担当を直し、「変更を保存」を押します。金額や合意状況などのメモは内容欄に記載します。確認予定の日付を入れても、入金済み・合意済みの扱いにはなりません。
5. 保存の確認表示を確認し、再読み込みして同じ内容が残るか確認します。

同じIDを更新し、未完了／完了、完了日時、未知の追加情報を保持します。内容を直す操作で完了にはしません。社員側の既存リクエストを新規作成・更新する操作でもありません。

## 保存前の保全と競合

- 開いた時点の対象を控え、保存直前に端末の最新記録を読み直します。対象が変わった場合は、上書きせず入力を残します。
- 対象以外の最新の追加、設定、領収書の編集などは保持し、対象の3項目だけを変えます。
- 実際の保存直前のデータベース全文と、対象の変更前・変更後を、別の端末内履歴キーに保存し、読み戻します。控えを保存・照合できなければToDoを変更しません。
- 本体を保存後、書き込んだ内容を全文読み戻して照合します。履歴の確認記録だけ保存できなかった場合は、本体の保存確認と区別して表示します。
- 同じ最新版の画面では、Web Locks対応時に編集保存と「Googleとまとめて同期」を順番に処理します。古い状態の画面は、本体の全体保存とGoogleまとめて同期の開始を止めます。

## 戻したい場合・保存できない場合

「編集履歴（この端末）」の「この内容を編集欄に戻す」で以前の内容・期限・担当を読み込み、確認して保存します。新しい履歴を残す操作であり、完了状態や他のデータを昔の状態へ戻す操作ではありません。

競合が出た場合は「入力内容を控えとして保存」で入力を残し、ほかの画面を閉じて再読み込みし、最新内容と比較してから編集を開き直してください。保存後の読み戻しが一致しない場合も、保存を連打せず最新内容を確認してください。全体初期化や古いバックアップの一括上書きは行いません。

## 制限と公開前の確認

- 手入力ToDoと編集履歴はこの端末・ブラウザの保存領域に残ります。この改修だけでは別端末と手入力データを同期しません。既存のGoogle連携・共有設定・認証権限を変更しません。
- 編集前の全文控えには案件・設定等も含まれます。公開リポジトリや第三者に置かず、安全な場所で保管してください。画像のバイナリは別のIndexedDBにあり、この控えだけに画像本体は含まれません。画像は編集処理で変更しません。
- 控えは自動削除しません。端末の空き容量が足りなければ編集保存を止めます。保存エラーを解決するためのデータ削除・サイトデータ初期化はしないでください。
- 古いv1.35以前の開いたままの画面は新しい競合防止に協力できません。実データ編集前に、同じブラウザのほかのCPG HUB画面を閉じ、最新版へ更新してください。Web Locks非対応環境では複数画面からの同時操作を避けます。
- 架空データで保存・競合・再読み込み・既存機能を検証しています。実機での編集前控え保存と、実データの修正結果の確認は別途必要です。候補コードのテストだけで実入金や正式合意を確認したことにはなりません。

## 開発時の検証

```sh
node tests/manual-todo.test.cjs
node tests/manual-todo-browser.cjs
node tests/takeover-browser.cjs
node tests/calendar-privacy.cjs
```

ブラウザテストにはPlaywrightとChromiumが必要です。`CHROMIUM_PATH`で実行ファイル、`CPG_TODO_ARTIFACTS`で新規編集テストの結果保存先を指定できます。会社の実データは使わず、Google通信を差し替えて実行します。
