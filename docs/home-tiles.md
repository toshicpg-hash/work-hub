# v1.48.0 ホームのまとめタイル

基準：f72de4c491545ab1752fbcd1ce3a85ab28215a2c（PR66、v1.47.7）。

ホームは「今日のまとめ」のタイル、タスクリクエスト件数、同期ボタンと結果、会社の動きのタイルの順です。0件でも表示します。期限切れ・緊急・入金遅れ・同期の注意は赤で示します。各タイルを押すと詳しいページへ移動します。

「対応中の緊急」は案件を緊急対応だけに絞り、受付からの経過時間を確認できます。「動いている案件」は案件一覧、「未入金」は数字の未入金、「立替 未提出」「提出済・未精算」は領収書を開きます。「今日までのToDo」の件数は従来どおり当日期限分です。リクエストや各集計の計算は変えません。

社長・全社・GMには「会社の動き」のタイルが出ます。社員数、今日未同期・読めなかった社員の人数を確認し、押すと会社の動きのページを開きます。「ホームへ戻る」で戻ります。下のメニューには追加しません。会社選択・GMの会社範囲は従来どおりです。社員別の立替表は領収書ページの先頭へ移しました。会社の動きで選んだ会社範囲（GMは担当会社）を引き継ぎます。

同期の成功結果の開閉はv1.47.7と同じです。自分のエラー・未完了・今日未同期・未送信報告・保存未確認はホームに残ります。会社側の注意で自分の成功結果の折りたたみを止めません。注意が多い場合はホームを下へスクロールしてください。

## 検証範囲

社員・社長・全社（gmCo=CP）・GM（CP限定）、390×844と820×900の合成Chromium。820×900はFoldの広い画面を想定したエミュレーションで実機CSS幅ではない。360pxは0件保持・横はみ出しを確認。各タイル移動、会社ページから戻る、会社選択範囲、移した立替表と法人カード除外、保存データ不変を検証。会社表示の既存試験は移動先をhomeからcompanyへ更新し内容のassertionを保持。同期試験は配置変更に合わせ座標一致から幅・高さの一致へ変更し、成功/失敗の判定を維持。画像はdocs/preview/home-*.png。実Google・Android実機は検証範囲外。

## 件数の意味

既存式を維持。今日までのToDoは当日期限分、期限切れは別タイル。立替タイルは本人端末分、社員別内訳は領収書。リクエストは既存genTodosのorder分。会社タイルは既存の同期状況と同じ読込済み一覧を数え、未読込は0人と断定しない。

## Access引渡待ちの境界

「Access引渡待ち」は受注済み・取消なし・仕事番号空欄の案件を数え、1件以上は赤く表示します。タップ先も同じ条件に絞り、一覧のチェックを外すと解除できます。0件でも表示します。

空白だけの仕事番号は空欄として扱います。取消・失注・引渡済み・施工中・入金済み・見積段階・仕事番号ありの除外と、共有閲覧案件を検証。既存CSVと自動ToDoの判定は変更しません。仕事番号があるのに受注段階のまま等の矛盾データでは、従来の段階だけの判定と件数が異なり得ます。データの自動補正は行いません。

Accessタイル追加後の合成画像では、390pxの同期欄・会社タイル、820×900の会社タイル下部はスクロールで確認します。タイル追加による縦方向の変化で、内容は下へスクロールして読めます。
