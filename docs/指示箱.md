# 指示箱（GM・全社からのタスクリクエスト）のデータの形

更新日：2026-10-30。v1.47.0（PR-A：社長の端末・GM／全社の端末）と v1.47.1（PR-B：社員の端末）の両方が、この形を守る。形を変えるときは、先にこの文書を直してから両方を合わせる。

## 全体

- 社長が出すタスクリクエストは、今まで通り社員の記録シートの「指示」タブ（指示ID `I-…`）。この文書の形とは別で、変えない。
- GM・全社の人が出すタスクリクエストは、**社員1人に1つの「指示箱」** に入れる。社員のシートには書き込まない。
- 社員の完了の報告は、**社員自身の記録シートの「指示の報告」タブ** に書く。指示箱には書かない。
- 行は消さない・並べ替えない。直すのは決まった列だけ。書いたあとは読み戻して確かめる。

## 1. 指示箱シート

| 項目 | 決まり |
|---|---|
| ファイル名 | `CPG HUB_指示箱_<社員一覧の氏名>`（例：`CPG HUB_指示箱_見本 一郎`） |
| 置き場所・持ち主 | 社長のドライブのフォルダ「CPG HUB データ」。作るのは社長の端末（持ち主は社長） |
| タブ | `指示` の1つだけ |
| 共有 | あて先の社員＝**閲覧者**。その社員に出せる人＝**編集者**（その社員の会社のGM、全社の人）。社長＝持ち主 |
| 作るとき | その社員に出せる人（GMか全社）が1人でもいるとき。共有を外した社員の指示箱は消さずに残す |

### 「指示」タブの列（1行目は見出し。この順番・この名前）

| 列 | 見出し | 中身 |
|---|---|---|
| A | 指示ID | `B-YYYYMMDD-xxxxxx`（B＝指示箱。日付は日本時間の指示日、xxxxxx は小文字英数6字。同じ指示箱の中で重ならないように作る） |
| B | 内容 | リクエストの内容（文字） |
| C | 期限 | `YYYY-MM-DD`（日本時間）。期限なしは空 |
| D | 指示日 | `YYYY-MM-DD`（日本時間） |
| E | 状態 | `未完了` または `取り消し` だけ（完了は書かない。完了は社員の「指示の報告」で決まる） |
| F | 出した人Gmail | 出した人のGoogleアカウント（小文字） |
| G | 出した人の表示 | 画面に出す名前。GM＝`GM 姓`（例 `GM 進藤`）、全社＝担当の略称（例 `黒木秀`）。ToDoでは「○○から」と出す |
| H | 取消日時 | 取り消したときの日時（ISO 8601、UTC。例 `2026-10-30T01:23:45.000Z`）。未完了のときは空 |
| I | 取消した人 | 取り消した人のGmail（出した人本人か社長）。未完了のときは空 |

- 足すとき：出す人の端末が `values.append`（A〜I、状態＝`未完了`、H・I は空）。足したあとに読み戻し、同じ指示IDの行があることを確かめる。
- 取り消すとき：E（`取り消し`）・H・I の3つだけを `values.update` で書く（その行だけ）。取り消せるのは、F が自分のGmailの行（社長はどの行も）。取り消しは完了扱いにしない。
- 一度 `取り消し` にした行を `未完了` に戻すことはしない（必要なら新しい指示を出す）。

## 2. 社員の記録シートの「連絡」タブ

- 書くのは**社長の端末だけ**（記録シートの持ち主）。社員の端末の同期では、このタブを消さない・書かない。
- 1行目は見出し、2行目に値（1行だけ）。

| 列 | 見出し | 中身 |
|---|---|---|
| A | 指示箱ID | その社員の指示箱のスプレッドシートID。指示箱が無いときは空 |
| B | 指示箱のリンク | `https://docs.google.com/spreadsheets/d/<指示箱ID>/edit` |
| C | 書いた日時 | 社長の端末が書いた日時（ISO 8601、UTC） |

- 社員の端末は、2行目のA列のIDで指示箱の「指示」タブを読む（アプリの「スプレッドシート」の許可で、IDから読める）。
- 見る人用一覧（`CPG HUB_見る人用一覧` の「一覧」タブ）にも、右端に `指示箱ID` の列を足す（GM・全社の端末が、出すときと状態を見るときに使う）。

## 3. 社員の記録シートの「指示の報告」タブ

- 書くのは**社員の端末だけ**（自分の記録シート）。無ければ社員の端末が作る。
- 1行目は見出し。行は足すだけ（消さない・直さない）。同じ指示IDの行が2つ以上あってもよい（書いた日時が一番新しい行を使う）。

| 列 | 見出し | 中身 |
|---|---|---|
| A | 指示ID | 指示箱の指示ID（`B-…`） |
| B | 状態 | `完了` |
| C | 完了日 | `YYYY-MM-DD`（日本時間） |
| D | 完了メモ | 文字（なくてもよい） |
| E | 書いた日時 | ISO 8601、UTC |

- 書いたあとに読み戻し、同じ指示ID・書いた日時の行があることを確かめる。確かめられないときは、完了を「送れていない」として次の同期でもう一度書く。

## 4. 状態の決め方（社長・出した人・社員の端末で同じ）

指示箱の行と、あて先の社員の「指示の報告」を、指示IDで突き合わせる。

1. 指示箱の状態が `取り消し` → **取り消し**（報告があっても取り消しとして扱い、完了扱いにしない。取消日時・取消した人を出す）
2. そうでなく、報告に `完了` の行がある → **完了**（一番新しい行の完了日・完了メモを出す）
3. どちらでもない → **未完了**。期限が今日（日本時間）より前なら **期限切れ**

- 社員の端末は、未完了（と期限切れ）だけを ToDo の「タスクリクエスト」欄に出す。印は「<出した人の表示>から」（例「GM 進藤から」）。
- 社員の端末が ToDo タブに書き出すときは、種類を `リクエスト` にする。社長・GM・全社の端末は、指示箱と「指示の報告」を正本にし、ToDo タブの書き出しには頼らない。

## 5. 古い版との互換

- 社長の「指示」タブ（`I-…`）の読み書きは変えない。移行はしない。
- 古い版の社員の端末は、指示箱を読まない。GM・全社の指示はまだ届かないが、消えたり古いものが出てきたりはしない（指示箱と「連絡」タブには触らないため）。出した人の画面には「v1.47.1 以降で同期すると届きます」と出す。
- 「連絡」「指示の報告」タブが無い古い記録シートでも、読むときにエラーにしない（タブの一覧を見てから読む）。
