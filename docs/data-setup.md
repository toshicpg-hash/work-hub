# CPG HUB の記録を社長のGoogleドライブに集める設定

社員が CPG HUB に入れた記録（案件・入金・立替の要点と、領収書の写真の控え）を、社長のGoogleドライブに集めて、社長が見られるようにするための手順です。

- 社員は、**自分のシートにだけ**書き込みます。ほかの社員のシートは見られません。
- 社長は、全員のシートを**見るだけ**です。社長の端末から社員のシートを書き換えることはありません。
- メモ・症状・住所の詳細と、練習用の（架空）の例は送りません。
- 自動では送りません。社員が「Googleとまとめて同期」を押したときに送ります。

---

## 1. はじめに（社長が一度だけ）

### Google Cloud の「テストユーザー」に社員を追加する

CPG HUB のGoogleログインは、PAPA HUB と同じ設定を使っています。この設定が「テスト中」のあいだは、**テストユーザーに追加した人しかログインできません**。社員を増やすたびに、次をしてください。

1. パソコンで Google Cloud Console（console.cloud.google.com）を開く（社長のアカウントで）
2. PAPA HUB で使っているプロジェクトを選ぶ
3. 左のメニューから「Google Auth Platform」→「対象」を開く
4. 「テストユーザー」の「＋ ユーザーを追加」で、社員の Gmail を入れて保存する

---

## 2. 社長の端末でする作業

### 管理をはじめる（最初の一度だけ）

1. CPG HUB を開き、ホームの **「Googleとまとめて同期」** を押して、社長のアカウントでログインする
2. 下のメニューの **「数字」** を開き、いちばん下の **「記録の送り先（Googleドライブ）」** を見る
3. 「管理（社長用）」の見出しを押して開き（v1.46.6 から、数字の画面の下の設定の欄は初めは閉じています）、**「管理をはじめる」** を押す
4. Googleの画面で、スプレッドシートとドライブ（CPG HUB が作ったファイル）の使用を **許可** する

### 2台目の端末（スマホとPCなど）で管理する

1. 2台目の端末でも、社長のアカウントでログインして「数字」の **「管理をはじめる」** を押す
2. 1台目で作ったフォルダ **「CPG HUB データ」** と **「CPG HUB_社員一覧」** を探して使います。「既存の管理データを読み込みました（社員○人）」と出れば完了です（新しいフォルダは作りません）
3. 同じ名前のフォルダが2つ以上あるときは、作成日の一番古いものを使い、「同じ名前のフォルダが○つあります」と出ます
4. 社員一覧の正本は **「CPG HUB_社員一覧」シート** です。ほかの端末で追加・共有を外したあとは **「一覧を読み直す」** を押してください（「社員を追加」「共有を外す」「社員の記録を読み込む」の前にも自動で読み直します）

### 社員を追加する

1. 「管理（社長用）」の欄に、**氏名** と **Gmail** を入れて **「社員を追加」** を押す
2. 次のように進みます（画面に1行ずつ出ます）
   - 社長のドライブに、フォルダ **「CPG HUB データ」** を作る（最初の1回だけ）
   - その中に、スプレッドシート **「CPG HUB_氏名」** を作る（タブ：案件・入金・立替・情報。ToDoタブは社員の最初の同期で足されます）
   - その社員の Gmail に **「編集者」** で共有する。社員には、Googleから案内メールが届きます
   - 同じフォルダの **「CPG HUB_社員一覧」** に、氏名・Gmail・シートを書く（クロもここを読みます）
3. 同じ Gmail の社員がもう一覧にあるときは追加できず、「○○さんはすでに追加されています」と出ます
4. 途中で止まったときは、画面に「途中で止まりました」と理由が出ます。もう一度「社員を追加」を押すと、新しいシートをもう1つ作ってしまうので、先に社長のドライブで中身を確かめてください

### 会社の動きを見る

1. ホームの **「会社の動き」** で **「社員の記録を読み込む」** を押す
2. 次が出ます
   - 社員ごとの最終同期の日時（**今日まだ同期していない人は赤**で出ます。社員は入力がなくても1日3回〈朝・昼・夕方〉同期する決まりです）
   - 動いている案件の件数（段階ごと）と、担当者ごとの一覧
   - 上の CP／CPY／AT で絞り込めます（v1.33 から、案件は案件の会社で分けます。会社が未設定の案件は担当者の所属の会社、案件の無いToDoとタスクリクエストは人の会社、立替は立替の会社。同期の状況はいつも全員を出します）
   - ToDo（社員ごと。期限切れ〈赤〉→今日→今後7日の一覧と、8日以降・期限なしの件数。期限切れがある人は名前が赤）。「ToDoはまだ届いていません」と出る人は、v1.29 以降で同期すると届きます
   - 未入金（担当者別・物件別、遅れの長い順）
   - 立替（社員別・会社別の、未提出と提出済・未精算の金額。無いときは「立替はありません」）
3. 最後に読み込んだ内容は、その端末に残します（30日まで。ログイン情報は残しません）。開き直すと「前回の読み込み（月/日 時:分）の内容です」と出ます。「Googleとまとめて同期」を押すと、社員の記録も読み込み直します

### 会社全体を見る（v1.30）

「社員の記録を読み込む」をすると、読み込んだ社員の案件とToDoが、社長の端末の案件・ガント・予定・ToDo・ホームの数字にも「社員の記録・見るだけ」として出ます。最後に読み込んだ内容は端末に残り、開き直しても見られます（30日まで）。最新にするには「Googleとまとめて同期」を押します。見る人の役割や共有が外れたときは、残した内容を消します。社長の端末から社員の記録を書き換えることはありません（「指示」タブだけは例外です）。

### タスクリクエストを出す

1. 「会社の動き」の「ToDo」の欄で、社員ごとの「リクエストの内容」と「期限」を入れて **「リクエストする」** を押す
2. その社員のシートの「指示」タブに1行足されます（タブ名と列名は「指示」のままです。社長が書くのは、行の追加と、取り消すときの「状態」だけです）
3. 社員が「Googleとまとめて同期」を押すと、社員のToDoに「リクエスト」の印付きで入ります。**同期するまでは届きません**。急ぐときはLINEでも伝えてください
4. 社員が完了にして同期すると、「最近7日の完了」に完了日と完了メモが出ます

### 会社・役割と、見る人（v1.31）

1. 「管理（社長用）」で、社員ごとに **会社**（CP／CPY／AT、複数可）・**役割**（社員／GM／全社）・**GMを務める会社** を決める（追加するとき、またはあとから「会社・役割」で）
2. 役割が **全社** の人には全員のシートを、**GM** の人にはGMを務める会社の社員のシートを、**閲覧者**で共有します。役割を外したり会社を変えたりすると、その分の閲覧の共有を外します（本人の編集者の共有は変えません）
3. GMは各社1人です。2人目を選ぶと入れ替えるか確認します（前の人は GM から外れ、役割が GM なら「社員」に戻ります）
4. 見る人がいると、フォルダに **「CPG HUB_見る人用一覧」**（氏名・Gmail・会社・役割・GMの会社・シートID だけ）を作り、見る人に閲覧者で共有します。管理画面の「見る人用のリンク」を見る人に送り、見る人は CPG HUB の「会社の動きを見る（管理者用）」に貼り付けてつなぎます
5. 「社員一覧」（共有IDなどを含む）は社長だけのものです。見る人には共有しません

### 社員の共有を外す（退職のときなど）

1. 「管理（社長用）」の社員一覧で、その人の **「共有を外す」** を押し、確認で **「共有を外す」** を押す
2. その人はシートを開けなくなります。**シートは消さずに残ります**（社長のドライブにあります）
3. 必要なら、Google Cloud の「テストユーザー」からも外してください

## 3. 社員の端末でする作業

### 記録シートにつなぐ（最初の一度だけ）

1. Googleから届いた共有の案内メール（「CPG HUBの記録用です。…」）を開き、**シートのリンクをコピー** する
   （リンクは `https://docs.google.com/spreadsheets/d/…` の形です）
2. CPG HUB の下のメニューの **「数字」** を開き、いちばん下の「記録の送り先（Googleドライブ）」の見出しを押して開き、**「記録シート（社員用）」** にリンクを貼り付ける
3. **「つなぐ」** を押す。Googleの画面が出たら、スプレッドシートとドライブ（CPG HUB が作ったファイル）の使用を **許可** する
4. 「記録シート「CPG HUB_氏名」につなぎました」と出れば完了です

### ふだんの使い方

- ホームか予定画面の **「Googleとまとめて同期」** を押すと、カレンダーと一緒に記録も送ります
- 結果は1行ずつ出ます。× が出た行は送れていません。通信の良いところで、もう一度押してください
- 領収書の写真は、**自分のGoogleドライブ** のフォルダ **「CPG HUB 領収書」** に控えとして入ります
  （ファイル名は「日付_会社_支払先_金額」。このフォルダは社長に「閲覧者」で共有されます。1枚につき1回だけ送ります）
- 「領収書」の画面の **「設定」** に氏名を入れておいてください。シートの「情報」タブに入ります

### うまくいかないとき

- **「このシートやフォルダを使う権限がありません」**：自分あてに共有されたシートではありません。社長から届いたメールのリンクか確かめてください
- **「許可されませんでした」**：Googleの画面で許可のチェックを外したときに出ます。もう一度押して、すべて許可してください
- **Googleの画面で「このアプリは確認されていません」やエラーが出る**：テストユーザーに追加されていない可能性があります。社長に連絡してください

## 4. 送る内容（参考）

| タブ | 中身 |
|---|---|
| 案件 | 受付番号・種類・段階・物件・部屋・依頼元・担当・受付日・予定日・実施日・見積額・受注日・仕事番号・施工完了日・請求日・請求額・入金予定日・入金済額・残額・遅れ日数・最終の動き（実際に起きたことの日付のうち、今日以前で一番新しい日。予定日・入金予定日は含めない。v1.46.3 から）・見積提出日・保留日・失注日・引渡日・入金日（最後の入金）・段階キー（new/site/quoted/hold/won/handed/built/billed/paid/lost）・受付日時（v1.30 から）・会社（CP／CPY／AT。v1.33 から。空は未設定）。右に足しただけで、前の列の並びは同じです |
| 入金 | 案件ごとの請求・経理への依頼・経理の返事・入金の履歴 |
| 立替 | 受付ID・日付・支払先・内容・区分・金額・会社・現場・仕事番号・状態・精算書番号・写真リンク・支払い方法・提出者 |
| ToDo | 内容・期限・担当・受付番号・物件・部屋・種類（自動／手入力／リクエスト。v1.29 では「社長から」）・状態（期限切れ／今日／今後／期限なし）。完了済みと領収書のお知らせは入れません |
| 指示 | 指示ID・内容・期限・指示日・状態（未完了／完了／取り消し）・完了日・完了メモ。社長が「リクエストする」で行を足し（最初の1回でタブを作ります）、取り消すときは状態だけを書き換えます。社員の端末は、完了にしたリクエストの「状態・完了日・完了メモ」だけを書きます。行の削除や並べ替えはしません（画面では「タスクリクエスト」と呼びます） |
| 情報 | 氏名・最終同期・版・管理者 |
| （社員一覧） | 氏名・Gmail・シートID・シートのリンク・状態・追加日・最終同期・共有ID・会社・役割・GMの会社（v1.31 で右の3列を追加） |
| （見る人用一覧「一覧」タブ） | 氏名・Gmail・会社・役割・GMの会社・シートID（共有を外した人は入れません） |

毎回、タブの中身をまるごと書き直します（前の内容は残りません。正本は各自の端末です）。
