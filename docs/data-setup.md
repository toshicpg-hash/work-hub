# CPG HUB の記録を社長のGoogleドライブに集める設定

社員が CPG HUB に入れた記録（案件・入金・立替の要点と、領収書の写真の控え）を、社長のGoogleドライブに集めて、社長が見られるようにするための手順です。

- 社員は、**自分のシートにだけ**書き込みます。ほかの社員のシートは見られません。
- 社長は、全員のシートを**見るだけ**です。社長の端末から社員のシートを書き換えることはありません。
- メモ・症状・住所の詳細と、練習用の（架空）の例は送りません。
- 自動では送りません。社員が「Googleとまとめて同期」を押したときに送ります。

---

## 1. はじめに（社長が一度だけ）

### Google Cloud の「テストユーザー」に社員を追加する

CPG HUB のGoogleログインは、PAPA HUB と同じ設定を使っています。この設定が「テスト中」のあいだは、**テストユーザーに追加した人しかログインできません**。社員を増やすたびに、次をしてください。

1. パソコンで Google Cloud Console（console.cloud.google.com）を開く（社長のアカウントで）
2. PAPA HUB で使っているプロジェクトを選ぶ
3. 左のメニューから「Google Auth Platform」→「対象」を開く
4. 「テストユーザー」の「＋ ユーザーを追加」で、社員の Gmail を入れて保存する

---

## 2. 社長の端末でする作業

### 管理をはじめる（最初の一度だけ）

1. CPG HUB を開き、ホームの **「Googleとまとめて同期」** を押して、社長のアカウントでログインする
2. 下のメニューの **「数字」** を開き、いちばん下の **「記録の送り先（Googleドライブ）」** を見る
3. 「管理（社長用）」の **「管理をはじめる」** を押す
4. Googleの画面で、スプレッドシートとドライブ（CPG HUB が作ったファイル）の使用を **許可** する

### 2台目の端末（スマホとPCなど）で管理する

1. 2台目の端末でも、社長のアカウントでログインして「数字」の **「管理をはじめる」** を押す
2. 1台目で作ったフォルダ **「CPG HUB データ」** と **「CPG HUB_社員一覧」** を探して使います。「既存の管理データを読み込みました（社員○人）」と出れば完了です（新しいフォルダは作りません）
3. 同じ名前のフォルダが2つ以上あるときは、作成日の一番古いものを使い、「同じ名前のフォルダが○つあります」と出ます
4. 社員一覧の正本は **「CPG HUB_社員一覧」シート** です。ほかの端末で追加・共有を外したあとは **「一覧を読み直す」** を押してください（「社員を追加」「共有を外す」「社員の記録を読み込む」の前にも自動で読み直します）

### 社員を追加する

1. 「管理（社長用）」の欄に、**氏名** と **Gmail** を入れて **「社員を追加」** を押す
2. 次のように進みます（画面に1行ずつ出ます）
   - 社長のドライブに、フォルダ **「CPG HUB データ」** を作る（最初の1回だけ）
   - その中に、スプレッドシート **「CPG HUB_氏名」** を作る（タブ：案件・入金・立替・情報）
   - その社員の Gmail に **「編集者」** で共有する。社員には、Googleから案内メールが届きます
   - 同じフォルダの **「CPG HUB_社員一覧」** に、氏名・Gmail・シートを書く（クロもここを読みます）
3. 同じ Gmail の社員がもう一覧にあるときは追加できず、「○○さんはすでに追加されています」と出ます
4. 途中で止まったときは、画面に「途中で止まりました」と理由が出ます。もう一度「社員を追加」を押すと、新しいシートをもう1つ作ってしまうので、先に社長のドライブで中身を確かめてください

### 会社の動きを見る

1. ホームの **「会社の動き」** で **「社員の記録を読み込む」** を押す
2. 次が出ます
   - 社員ごとの最終同期の日時（**3日以上同期していない人には注意**が出ます）
   - 動いている案件の件数（段階ごと）と、担当者ごとの一覧
   - 未入金（担当者別・物件別、遅れの長い順）
   - 立替（社員別・会社別の、未提出と提出済・未精算の金額）
3. 読み込んだ内容は、画面を閉じると消えます（端末には残しません）

### 社員の共有を外す（退職のときなど）

1. 「管理（社長用）」の社員一覧で、その人の **「共有を外す」** を押し、確認で **「共有を外す」** を押す
2. その人はシートを開けなくなります。**シートは消さずに残ります**（社長のドライブにあります）
3. 必要なら、Google Cloud の「テストユーザー」からも外してください

---

## 3. 社員の端末でする作業

### 記録シートにつなぐ（最初の一度だけ）

1. Googleから届いた共有の案内メール（「CPG HUBの記録用です。…」）を開き、**シートのリンクをコピー** する
   （リンクは `https://docs.google.com/spreadsheets/d/…` の形です）
2. CPG HUB の下のメニューの **「数字」** を開き、いちばん下の **「記録シート（社員用）」** にリンクを貼り付ける
3. **「つなぐ」** を押す。Googleの画面が出たら、スプレッドシートとドライブ（CPG HUB が作ったファイル）の使用を **許可** する
4. 「記録シート「CPG HUB_氏名」につなぎました」と出れば完了です

### ふだんの使い方

- ホームか予定画面の **「Googleとまとめて同期」** を押すと、カレンダーと一緒に記録も送ります
- 結果は1行ずつ出ます。× が出た行は送れていません。通信の良いところで、もう一度押してください
- 領収書の写真は、**自分のGoogleドライブ** のフォルダ **「CPG HUB 領収書」** に控えとして入ります
  （ファイル名は「日付_会社_支払先_金額」。このフォルダは社長に「閲覧者」で共有されます。1枚につき1回だけ送ります）
- 「領収書」の画面の **「設定」** に氏名を入れておいてください。シートの「情報」タブに入ります

### うまくいかないとき

- **「このシートやフォルダを使う権限がありません」**：自分あてに共有されたシートではありません。社長から届いたメールのリンクか確かめてください
- **「許可されませんでした」**：Googleの画面で許可のチェックを外したときに出ます。もう一度押して、すべて許可してください
- **Googleの画面で「このアプリは確認されていません」やエラーが出る**：テストユーザーに追加されていない可能性があります。社長に連絡してください

## 4. 送る内容（参考）

| タブ | 中身 |
|---|---|
| 案件 | 受付番号・種類・段階・物件・部屋・依頼元・担当・受付日・予定日・実施日・見積額・受注日・仕事番号・施工完了日・請求日・請求額・入金予定日・入金済額・残額・遅れ日数・最終の動き（案件の日付のうち一番新しいもの） |
| 入金 | 案件ごとの請求・経理への依頼・経理の返事・入金の履歴 |
| 立替 | 受付ID・日付・支払先・内容・区分・金額・会社・現場・仕事番号・状態・精算書番号・写真リンク・支払い方法・提出者 |
| 情報 | 氏名・最終同期・版・管理者 |

毎回、タブの中身をまるごと書き直します（前の内容は残りません。正本は各自の端末です）。
