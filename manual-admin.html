CPG HUB 管理者向けマニュアル（社長・全社・GM）

このマニュアルは v1.50.66用　最終改訂日：2026年11月14日

社員の毎日の使い方（受付・案件・ToDo・予定・ガント・領収書・同期・困ったとき）は、社員向けの使い方マニュアルにあります。改訂履歴も、社員向けのマニュアルの最後にあります（改訂履歴）。

もくじ
  1. 画面の上の部分
  2. 社長用（管理）（正式な氏名を直す）
  3. 会社の動きを見る人用（全社・GM・経理・業務管理）（タスクリクエストを出す）

画面の上の部分（社長・全社・GM）

どのタブも、いちばん上は会社・人の細い1行です。押すと選べます。注意があるときだけ赤い札（期限切れToDo・緊急・失注日なし・未読込の人数）が出て、押すとその一覧が開きます。説明は「ⓘ」を押したときだけ出ます。大きな「Googleとまとめて同期」はホームだけで、ほかのタブは小さな「日時 ↻」で同期します。会社の動きの「記録を読み込む」は見出しの下、「一覧を読み直す」は「ⓘ」の中です。仕事用カレンダーと会社・人の結び付けは、「数字」の下の「仕事用カレンダーの対応設定（この端末）」でします（予定のタブからは外しました）。

社長用（管理）

社長のアカウントでログインしたときだけ使えます。詳しい手順は 記録を集める設定（data-setup.md） にあります。

社員を追加する

  1. 先に、Google Cloud の「対象」で、その社員をテストユーザーに追加する
  2. CPG HUB の 数字 → 一番下の「管理（社長用）」の見出しを押して開き、氏名とGmailを入れて 社員を追加
  3. その人に共有メールが届きます。ホームの「初期設定」を順番どおりに進めてもらう（最初の同期のあとに、その人のGoogleカレンダーを、予定を見てよい人に共有してもらいます。やり方）。共有先は、社員を追加したときと、会社・役割を保存したときに、その人の記録シートの「予定の共有先」に書きます
  4. 社長がGoogleカレンダーで、共有カレンダー「CPG HUB」をその人に共有する：PCのGoogleカレンダーで「CPG HUB」の「設定と共有」→「特定のユーザーまたはグループと共有する」→ その人のGmailを足し、権限を 「予定の変更」 にして送信。その人に招待メールが届くので、承諾してもらう（社員向けの手順）。共有しないと、その人が「Googleカレンダーに登録」を押したときに「『CPG HUB』カレンダーの共有がまだです」と出ます
  5. 社長と専務の側でも、端末ごとに次をする（設定は端末ごとです。スマホとPCの両方で使うなら、両方でします）
    1. 共有の案内メールが届いたら、Googleカレンダーでその人のカレンダーを追加する（メールの「このカレンダーを追加」）。全社・経理・業務管理・GMの人も、自分が共有先になった人について同じことをします
    2. CPG HUB で Googleとまとめて同期 を押す（次の対応設定で結び付けたカレンダーは、「予定画面に表示するカレンダー」で選ばなくても読みます）
    3. 数字 →「仕事用カレンダーの対応設定（この端末）」で、そのカレンダー・用途「人物を確認した仕事専用」・会社・その人を選び、確認のチェックを入れて保存。カレンダーの欄では、社員のカレンダーは「進藤 ○○（Gmailの先頭）」のように人の名前で出ます。社員一覧のGmailと同じカレンダー（その人の本人のカレンダー）は、この保存をしなくても、見てよい人なら自動でその人の予定として出ます（対応設定の画面に「→ ○○（自動。…）」と出ます）。会社を決めたいときや、ほかの用途にしたいときだけ保存してください（保存した対応が優先されます）

    共有カレンダー「CPG HUB」は、この手順は要りません。ほかの人の予定を見る端末（社長・全社・GM・経理・業務管理）では、「CPG HUB」を自動で表示し、「複数の人が使う仕事用」として扱います（HUBの案件は担当の人の予定として出ます）。

  6. ホームの「会社の動き」を押して開いたページで 社員の記録を読み込む を押すと、みんなの様子が見られます（今日まだ同期していない人は赤で出ます。社員は1日3回同期する決まりです。専務はいつも「黒木秀」、同じ名字の人は「黒木祐」のように名の1字を付けて区別します）
  7. 「会社の動き」は、上から 同期の状況 → ToDo → タスクリクエストを出す → 動いている案件 → 未入金 の順です。ToDoと動いている案件は、社員ごとに1行（名前と件数）に畳んであります。名前を押すと開きます。「タスクリクエストを出す」も畳んであり、見出しを押すと入れる欄が開きます（書きかけのときは開いたまま）
  8. 「ToDo」の欄では、社員ごとに 期限切れ（赤）→ 今日 → 今後7日 の順にToDoが出ます。期限切れがある人は名前が赤になります。8日以降と期限なしは件数だけです。「ToDoはまだ届いていません」と出る人は、その人のCPG HUBを最新の版にして「Googleとまとめて同期」を押してもらうと届きます

タスクリクエストを出す

GM（その会社の社員あて）、全社の人（全員あて）、経理・業務管理の人（担当の会社の社員あて）もタスクリクエストを出せます。社長の画面の「タスクリクエスト（GM・全社・経理・業務管理から）」に、出した人の表示付きで全部出て、社長はどれでも取り消せます。GM・全社の人には、社員ごとの「指示箱」（社長のドライブの「CPG HUB データ」の「CPG HUB_指示箱_氏名」）が、会社・役割の保存時に一覧で確認してから編集者で共有されます。社員の記録シートは見るだけのままです。GMを外したり入れ替えたりしても、その人が出した未完了のリクエストは残ります（社長が取り消せます）。

タスクリクエストは代表からの必ずやる依頼です。社員のToDoの画面では、期限に関係なく一番上の「タスクリクエスト」の欄に出ます。社長・全社・GMの端末のToDoの画面でも、読み込んだ社員のリクエストが一番上に、担当のバッジ付きで出ます（取り消した・完了したリクエストは出ません）。

  1. ホームの「会社の動き」を押して開いたページで 社員の記録を読み込む を押す
  2. 「会社の動き」の「ToDo」のすぐ下の「タスクリクエストを出す」で、宛先の枠を押すと社員の一覧が開きます。出したい人にチェックを入れます（何人でも。全員を選ぶ・選び直す もあります）。「内容」と「期限」（今日・明日・今週中 でも入ります）を入れて リクエストする。チェックした人それぞれに1件ずつ出ます。ホームの「会社の動き」の タスクリクエストを出す からも開けます
  3. 「○○さん：出しました」と人ごとに出ます（出せなかった人は理由付きで出て、入れた内容と宛先は残ります）。社員が同期するまで届かないので、急ぐときはLINEでも伝えてください
  4. 社員の名前の横に「リクエスト 未完了 ○・期限切れ ○」が出ます。未完了は期限の近い順で、期限切れは赤です。社員が完了にして同期すると「最近7日の完了」に完了日と完了メモが出ます（もう一度「社員の記録を読み込む」を押すと最新になります）
  5. やめたリクエストは 取り消す → 確認で 取り消す。社員の次の同期で、社員のToDoから消えます
  6. 「社員のToDo」には、社員が自分で持っているToDo（案件の自動のToDoと手入力のToDo）が出ます
  7. ホームの「タスクリクエスト（全体）」には、社長・GM・全社の人が出した未完了の数と、出した人ごとの内訳が出ます。「期限切れ」と「5日以内」を分けて出し、期限切れがあると赤くなります。押すと指示一覧で、先の期限・期限なしも見られます。一覧では「全部／社長／出した人ごと」に切り替えられます（見るだけで、ここからは完了・取消はできません）

会社全体を見る（案件・ガント・予定・ToDo）

読めなかった人がいるとき：社員の記録は1人ずつ読みます。読めなかった人だけ、少し待って最大2回読み直します（Google側の一時的な不具合・時間切れ・通信の失敗のとき。成功した人は読み直しません）。Googleの回数制限のときは、制限が戻るまで長めに待って最大4回読み直し、その間はほかの人の読み込みも止めます（社員が多いと、全体で1〜2分ほど長くかかることがあります）。それでも読めなかった人は「読めませんでした（理由）」と出ます。0件ではありません。理由は「Googleの回数制限（429）」「Google側の一時的な不具合（503など）」「時間切れ（45秒）」「通信の失敗（電波・接続）」「権限がありません（403）」などに分けて出ます。回数制限のときは、数分おいてからもう一度読み込んでください。「同期の状況」の下に、読み込みにかかった時間（全体と1人あたり）が出ます。

  1. ホームの「会社の動き」を押して開いたページで 社員の記録を読み込む を押す
  2. 読み込んだ社員の案件とToDoが、案件・ガント・ToDo（予定は今日以前が期限の未完了ToDoのみ）と、ホームの数字（期限切れ・今日・緊急・動いている案件・未入金）にも出ます。ホームの数字は会社全体になります
  3. 社員の分には 社員の記録・見るだけ の印が付きます。押すと詳細が見られますが、直したり消したりはできません。直すときは担当の社員に頼んでください
  4. ガントとToDoは、担当で絞り込めます
  5. 数字 の画面（月別／全期間の見積提出・受注・失注・決定率・受注額、失注の理由、種類別と、今の未入金。数え方は社員向けの「数字」）も、社員の案件を含めた会社全体の数字になります。上の 全社／CP／CPY／AT で会社ごとに絞り込め（案件の会社で分け、未設定なら担当者の所属の会社）、「担当別」の表で担当ごとの見積提出・受注・受注額・未入金が見られます。画面の上に「社員の記録（月/日 時:分 読み込み）を含めた会社全体の数字です」と出ます。「社員の記録はまだ読み込んでいません」と出ているときは、この端末で入力した分だけの数字なので、「Googleとまとめて同期」を押してください。GMの端末では、数字はGMを務める会社の分だけで、会社の絞り込みはその会社に固定です（「会社の動き」の絞り込みも同じで、GMの会社に固定です。全社の役割の人は、社長と同じく全社から選べます）
  6. 「会社の動き」の CP／CPY／AT で、会社ごとに絞り込めます。案件は案件の「会社」で分けます（会社が未設定の古い案件は、担当者の所属の会社で分けます）。同期の状況は、いつも全員分が出ます
  7. 社員がHUBからGoogleカレンダーに入れた予定は、Googleの予定として表示します。案件の進捗印は足しません。社員のToDoも、期限が今日以前のものだけ今日の欄にも出ます
  8. 最後に読み込んだ内容はこの端末に残り、アプリを開き直しても「前回の読み込み（月/日 時:分）の内容です」と出て、そのまま見られます（30日まで。ログイン情報は残しません）。最新にするときは Googleとまとめて同期 を押すと、カレンダーに続けて社員の記録も読み込みます（結果に「社員の記録：○人・案件○件」の行が出ます）
  9. 社員の同期が古いと、古いままの内容が出ます（「同期の状況」で最終同期を確かめてください）。古い版で同期した社員の案件は、見積提出・保留などの日付が届いていないことがあり、ガントの帯が一部だけになります

「管理（社長用）」の社員一覧では、1人ごとに、名前とGmailの行の下に 正規氏名 会社・役割 共有を外す が並びます。

「管理（社長用）」の社員一覧の「最終同期」は、社員の記録を読み込んだときに、その人の記録シートから読んだ日時です。まだ読み込んでいないときは「未読込」と出ます。最新にするときは「会社の動き」で 社員の記録を読み込む（または「Googleとまとめて同期」）を押してください。

社員に会社全体の数字を見せる（「数字」の「会社全体」）

  1. 会社ごとに「CPG HUB_会社の数字_CP」などのシートを作り、その会社に所属する社員にだけ「見るだけ」で共有します。2社に所属する人には両方、ほかの会社の人には共有しません。社員の記録シート（立替・領収書のタブがある）は共有しません
  2. 最初の1回（と、社員の会社を変えたとき）は、「管理（社長用）」の 会社の数字の共有を合わせる を押し、確認の一覧を見て実行します（会社・役割の保存や社員の追加でも合わせます）。各社員の記録シートに「会社の数字の場所」タブも書きます
  3. 「会社の動き」で 社員の記録を読み込む を押すたびに、会社ごとの数字を書き直します。その会社の社員を1人でも読めなかったときは、その会社の数字は前のままにします（一部だけの数字で上書きしない）。結果は「数字」の ⓘ に出ます
  4. 書き出すのは、その会社の案件の数字に使う列（種類・段階・担当・物件・部屋・依頼元・金額・日付・失注理由・請求と入金）だけです。住所・メモ・症状・立替・領収書は書きません
  5. 社員の端末では、「数字」の「会社全体」でだけ使います。案件・予定・ToDo・領収書の画面は今までどおりです

社員のカレンダーを名前で表示する（社長の Google カレンダー）

  1. Google カレンダーのアプリで、社員のカレンダーがメールアドレスで出ているときに使います。
  2. 数字 →「Googleカレンダー連携」を開き、社員のカレンダーを名前で表示する を押します。初めてのときは Google の確認画面（カレンダーの一覧を変える許可）が出るので、許可します。
  3. 変える一覧（例：メールアドレス → 小泉 ○○）が出るので、確かめて OK を押します。社員一覧の Gmail と同じカレンダーだけが、社員一覧の氏名になります。
  4. 変わるのは社長の Google カレンダーの中の表示だけです（スマホ・パソコンとも）。持ち主の名前・予定・共有は変わりません。同期のしかたも変わりません。
  5. 「CPG HUB」、社長のカレンダー、社員一覧にいない人のカレンダー、すでに名前になっているカレンダーは変えません。

    6. 社員が作った「担当：社長」の ToDo

    1. 社員が自分の端末で担当を「社長」にして作った ToDo は、社長の画面に「社員の記録・見るだけ」として出ます。カードには「○○さんの記録」と、だれの記録かが出ます。
    2. 終わったら 済みにする を押します。社長の画面から消えます。社長のほかの端末でも、次の同期で消えます（社員一覧のファイルの「社長の済み」タブに残します）。
    3. 作った人の記録は変わりません。作った人の画面からも消したいときは、その人に完了してもらってください。
    4. 同じ内容でも、期限が違う新しい ToDo は別のものとして出ます。

    受付番号の記号（人ごとのアルファベット3文字）

    1. 受付番号の頭は、人ごとのアルファベット3文字です（例：KOI-0017）。番号を見ただけで、だれの案件か分かります。
    2. 名前から決める：「管理（社長用）」の社員一覧で 役割を変える を押し、「受付番号の記号」にアルファベット3文字を入れて保存します（例：大平→OHI、小泉→KOI。同じ名字が2人なら、名字と名前の頭文字で 黒木秀一→KH・黒木祐次郎→KY）。欄には、今の記号か、なければ Gmail の頭2文字が案として入っています。全角・小文字で入れても、半角の大文字にそろえます。社員を追加するときも入れられます。
    3. ほかの人（共有を外した人も）が使っている記号や、会社名と紛れる CPY・CPG、英字3文字でないものは、保存の前に止めて知らせます。
    4. 前に2文字の記号を入れた人（例：QX）は、社員一覧に「2文字・3文字に入れ直してください」と出ます（一覧の上に人数も出ます）。「役割を変える」の欄は空で、「今は QX（2文字）。3文字で入れ直してください」と出るので、3文字を入れて保存してください。入れ直すまでは、今の2文字で受付番号が付きます（例：QX-0018）。入れ直したあとの受付から3文字になります。前の2文字 KH と、新しい3文字 KHI は別の記号として使えます。
    5. 空のままの人には自動で決めます（見分けにくい I・O を除いたランダムな3文字）。会社の数字の共有を合わせる を押したとき、社員を追加したとき、会社・役割を保存したときです。
    6. 決めた記号は、社員一覧の「受付番号の記号」の列と、各社員の記録シートの「受付番号の記号」タブに書きます。社員の端末は、次の同期で受け取ります。
    7. 社員一覧では、1人ごとに 受付番号 QX- のように出ます。
    8. 全員分をまとめて入れる：社員一覧の上の 受付番号の記号をまとめて入れる を押すと、1人1つの欄が出ます。3文字を入れて まとめて保存する を押します。空の欄は今の記号のままです。形が違う・ほかの人と重なるときは、保存の前に止めて知らせます（入れた値は消えません）。
    9. 記号や表示名だけを変えたときは、共有の付け替えはしません（社員一覧と、その人の記録シートの「受付番号の記号」だけを書くので、すぐ終わります）。会社・役割・GMの会社・担当の会社・統括GMを変えたときは、今までどおり共有を確かめて付け替えます。
    10. 自動で決めた記号は、そのあと自動では変えません。あとから「役割を変える」で変えると、変えたあとの新しい受付からその記号になります（今までの番号はそのまま）。共有を外した人の記号も、ほかの人には使いません。
    11. 今までの受付番号（U-0004 など）は変わりません。ToDo・領収書・カレンダーの予定との結び付きは、そのままです。社長の端末の受付番号は「U」のままです。

    予定の共有（社員のGoogleカレンダー）

    1. 共有先（その人の予定を見てよい人）は、社長の端末で、社員一覧の役割から決めます：社長、全社の人（全員の分）、GM（その人を見られるGM。同じ1社だけに所属する一般社員）、経理・業務管理（その人の会社を担当する人。複数の会社に所属する人は、そのどれかを担当する人）。本人と、共有を外した人は入りません
    2. 社員を追加したときと、会社・役割を保存したときに、各社員の記録シートの「予定の共有先」タブに書きます。書き直したいときは、「管理（社長用）」の 予定の共有先を書く を押します。押すと画面の下に「予定の共有先を書いています 2／8：○○さん」と進み具合が出て、最後に「完了しました（8人分を書きました。変わった人：○○さん（＋△△）／変わらなかった人 7人）」のように、人ごとに足した相手（＋）・外れた相手（－）が出ます。変わらなければ「変更はありませんでした」と出ます。途中で止まったときは、止まった人と理由が出ます。それまでの分は書けているので、もう一度押すと続きから書き直します。このボタンは共有先（だれに共有するか）を書くだけです。実際にカレンダーを共有するのは本人です。変わった人には、自分の端末で「予定の共有」をもう一度押してもらってください（足りない相手だけ足されます）
    3. 社員は、自分の端末で「予定の共有」を押します。共有する相手を確かめてから、メインのGoogleカレンダーを「見るだけ」で共有します。足りない相手だけ足し、外したり、権限を下げたりはしません。共有した相手には、Googleからお知らせのメールが届きます
    4. 「管理（社長用）」の社員一覧に、予定の共有の状況が出ます（「会社の動き」で 社員の記録を読み込む を押したあと）：済／まだ：○○（本人がもう一度押すと足されます）／まだHUBで共有していません。役割が変わって、今は共有先ではない人に共有が残っているときは 要確認 と出ます。HUBは自動では外しません。外すかは確かめてから、本人のGoogleカレンダーの設定で外してもらいます

    はじめに1回：Google Cloud にカレンダーの共有の許可を足す（社長がする）

    「予定の共有」のボタンは、Googleカレンダーの共有を変える許可（https://www.googleapis.com/auth/calendar.acls）を使います。ボタンを押したときだけ求め、起動したときやふだんの同期では求めません。

    1. パソコンで console.cloud.google.com を開き、CPG HUB のプロジェクトを選ぶ
    2. 「Google Auth Platform」→「データアクセス」→「スコープを追加または削除」
    3. 一覧から、または「手動でスコープを追加」に https://www.googleapis.com/auth/calendar.acls を入れて追加し、「更新」→「保存」
    4. アプリが「テスト」のままなら、許可できるのはテストユーザーだけです（社員を追加するときと同じ「対象」のテストユーザー）。社員が許可するとき、「Googleで確認されていません」と出たら「続行」を押してもらいます

    この設定をしていないと、社員がボタンを押したときに「共有の権限がありません」と出て、共有しません。そのときは、マニュアルの「ブラウザで共有する」の手順で共有してもらえます。

    会社・役割（全社・GM・経理・業務管理）を決める

    1. 数字 → 「管理（社長用）」で、社員を追加するときに「会社（複数可）」「役割」「GMを務める会社」を選ぶ。あとから変えるときは、その人の 会社・役割 → 選んで 保存する
    2. 役割：社員＝自分の記録だけ。GM＝同じ1社だけに所属する一般社員の記録を見る（複数会社・全社・GMは除く）。全社＝全員の記録を見る（例：専務）。全社の人がある会社のGMも務めるときは、役割を「全社」にして「GMを務める会社」を選びます（見る範囲は全社が優先です）。経理・業務管理＝「担当の会社」（人ごとに選ぶ。例：経理：CP・CPY）に所属する社員の記録（案件・ToDo・予定など）を、見るだけで見る。その会社のGMも含みます。複数の会社に所属する人（専務など）は、所属の会社のどれかが担当の会社なら見えます（電話対応で居場所が分かるように）。よその会社だけに所属する社員は見ません。GMからは、今までどおり複数の会社に所属する人は見えません。タスクリクエストは出せません。表示は「経理：CP・CPY」「業務管理：3社すべて」の形です
    3. 領収書：経理は、担当の会社の社員の立替・領収書を見られます。複数の会社に所属する人の分は、担当の会社の分（立替の「会社」が担当の会社の行）だけです。業務管理は、ほかの人の立替・領収書（立替・精算書・法人カード）を見ません。一般社員も、ほかの人の領収書は見ません（今までどおり）。ただし、見る人には記録シート全体を「閲覧者」で共有しているので、Googleスプレッドシートを直接開くと「立替」のタブも見えます。HUBの画面に出さないだけです
    4. 表示名（任意）：画面に出す名前です。肩書で出したい人（例：専務）は、その人の 会社・役割 で「表示名」に入れて保存します。空なら氏名（フルネーム）で出ます。担当・予定の札・会社の動き・タスクリクエストの出した人・ToDo・会社と人の選択肢など、名前が出るところで表示名を使います。同じ表示名や、ほかの人の氏名と同じ表示名の人がいるときは「専務（氏名）」のように氏名を添えて区別します。案件・ToDoの担当や記録シートの氏名、Access用のCSVなど外に出す名前は、今までどおり氏名のままです。社長の担当は、いつも「社長」と出ます
    5. 表示名は、社員一覧と見る人用一覧の最後の列「表示名」に入ります。古い版の社長の端末で社員を追加したり会社・役割を保存したりすると、この列が消えます。表示名を入れる前に、社長の端末（スマホ・PCの両方）を最新の版にしてください。全社・GMの人の端末も最新にしてもらうと、その端末でも表示名で出ます
    6. 経理・業務管理を初めて入れる前に、社長の端末（スマホ・PCの両方）を最新の版にしてください。社員一覧と見る人用一覧に、新しい列「担当の会社」を足しました。古い版の端末は「経理」「業務管理」と「担当の会社」を知らないので、その端末で社員を追加したり会社・役割を保存したりすると、「担当の会社」の列が消え、役割が「社員」に戻り、見る人の共有も外れます。全社・GMの人の端末も、最新の版にしてもらってください。手順：①社長の端末をすべて最新にする（画面の上の版が、このマニュアルの先頭の版と同じか確かめる）②全社・GMの人の端末も最新にしてもらう ③そのあとで、経理・業務管理の人の役割と担当の会社を保存する
    7. 1つの会社にGMを2人以上置けます。すでにGMがいる会社を選ぶと「○○のGMはすでに○○さんです。2人目のGMとして追加しますか？ 入れ替えますか？」と出ます。
      • 2人目のGMとして追加する：今のGMもGMのままです。2人とも、見られる記録・指示箱（タスクリクエスト）・見る人用一覧・予定の共有先・会社の数字が同じになります。
      • ○○さんと入れ替える：その人はGMから外れます（役割がGMなら「社員」に戻ります）。
      • どちらも、そのあと共有変更の一覧を確認します。旧共有・帰属不明の共有は残して要確認にします。
      • GMの1人を外しても、ほかのGMの共有はそのまま残ります。
      • GM同士は、おたがいの記録は見ません（GMが見るのは、その会社だけに所属する一般社員の記録です）。
    8. 統括GM：同じ会社にGMが2人以上いて、その中に上の立場の人がいるときは、その人の 役割を変える で「統括GM」に印を付けて保存します。
      • 統括GMは、その会社の一般社員に加えて、同じ会社のほかのGMの記録も見ます（記録シートの閲覧・予定の共有先・会社の動き・タスクリクエストを出す相手）。
      • 逆に、ほかのGMが統括GMの記録を見ることはありません（一方向）。
      • 統括GMは会社ごとに1人です。2人目に付けようとすると、保存の前に止まります。先に今の人の印を外してください。
      • 印を外して保存すると、ほかのGMの記録シートの共有は外れます。一般社員の記録は、GMとして見たままです。
      • 印は役割がGMのときだけ働きます。GMが1人の会社では、付けても見える範囲は変わりません。
      • 社員一覧と見る人用一覧の最後の列「GM統括」に「統括」と入ります。
    9. 保存操作ではまず共有一覧を確認し、確認後に見る人へ、見てよい社員のシートを 閲覧者 で共有します。役割を外したり会社を変えたりすると、当機能の付与記録を確認できた共有だけ解除します。旧共有などは残して要確認にします（役割変更では本人の編集者の共有は維持します）
    10. 見る人がいると「見る人用のリンク」が出ます。リンクをコピー して、見る人に送ってください（LINEなど）

    保存中の表示：確認の一覧で実行すると、画面の下に進み具合が出ます（「共有の一覧を読んでいます」→「反映中 3／8：○○さんの記録シートに△△さんを見るだけで共有」→「見る人用一覧を書き直しています」→「社員一覧に保存しています」→ 指示箱のお知らせ・予定の共有先 →「完了しました」）。共有は1件ずつ、変える前と後に読み直して確かめるので、人数が多いと数分かかります。「完了しました」が出るまで、画面を閉じずに待ってください。役割は、共有と見る人用一覧のすぐあとに社員一覧へ保存します。そのあとの指示箱のお知らせ・予定の共有先が書けなかったときは、注意が出ます（役割と共有は保存済みです）。止まったときは「ここで止まりました：…」と、止まった所と理由が出ます。できたところまでは残っているので、もう一度保存すると、続きから確かめて進めます。

    会社・役割を保存するときは、先に「だれのシートを・だれに・どの権限で」共有するかの一覧が出ます。確かめてから実行してください。前からある共有や、だれが付けたか分からない共有は外さずに「要確認」と出します。役割を外しても「要確認」の共有が残っていると、その人はGoogleで見られるままです。必要なら社長がGoogleドライブで確かめてください。共有を変えた記録は、社員一覧の「共有管理履歴」に残ります。管理の操作は、1台の端末の1つの画面で行ってください。

    社員の正式な氏名を直す

    1. 数字 → 「管理（社長用）」→ その社員の 正規氏名
    2. 新しい氏名を入れて 変更内容を確認。直す前・直した後を確かめて保存する（「やめる」や確認を閉じると変わりません）
    3. 社員・全社・GMの端末は、次の同期で新しい氏名で出ます。過去の案件・ToDo・精算書の名前は書き換えません。同じ姓名の人はGmailで区別します

    保存の途中で通信が切れたときは、うまくいったと考えず、同じ名前でもう一度確かめてください。直した記録は「社員氏名履歴」に残ります。

    売上報告（試作・社長の端末だけ）

    1. 数字 のいちばん上の「グループ各社売上進捗報告」（社長だけ）を開いて 試作用のシートを作る（架空のデータ） を押すと、社長のドライブ「CPG HUB データ」に「CPG HUB_売上報告（試作・架空）」ができ、架空の数字で画面が出ます（共有はしません）
    2. 表は3つです。スマホで見やすいように、表ごとにタブを分けます（「2026-10 会社」「2026-10 担当」「2026-10 受注」のように、年-月と表の名前）。どのタブも1行目が見出しで、見出しの行と会社の列は止めてあるので、横や下へ動かしても見えます。1か月を1つのタブ（「2026-10」）にまとめた形も読めます。
      ①「会社｜目標売上｜目標粗利｜実績売上｜実績粗利｜前月売上｜前月粗利｜最終粗利予想｜人件費｜Notes未入力｜社長確認日｜本部長確認日｜GM確認日｜GMの名前｜更新日」
      ②「会社｜区分｜担当｜状態｜物件数｜基準値｜金額｜粗利」（状態は 完了・施工中・その他。営業外売上は「その他」）
      ③「会社｜日｜受注件数｜受注金額」（毎日の受注）
    3. 数字を入れる：月を選んで「数字を入れる」を開き、会社（CP・AT・CPY）と、入れるもの（毎日の受注・会社の数字・担当者別）を選びます。数字を直して シートに保存 を押すと、変えたマスだけをシートに書き、その会社の「更新日」を今日にします。毎日の受注で、まだシートにない日は行を足します。シートで誰かが先に同じマスを変えていたり、式が入っているマスは、書かずに止めます（「読み直す」を押してから入れ直してください）
    4. 毎日の確認：シートの「2026-11 確認」のタブに、会社・日ごとに社長・本部長・GMのチェックボックスがあります。スマホで押すだけで付けられます。HUBには今日の済み・未と、今月の確認した日数が出ます。社長は 社長の確認をした（今日） を押すと、シートの今日のマスに印が付きます（そのマスだけを書きます）
    5. 担当者別の「合計」は、完了と施工中を足したものです（営業外売上などの「その他」は入れません）。施工中の粗利は今の3社報告と同じく空で、「—」と出ます
    6. 本物の数字のシートを読んでいるときは、試作用のシートを作り直す（架空） は出ません
    7. 会社は CP・AT・CPY の順に出します（シートの行の順によりません）。画面では、目標粗利率・粗利率・達成率・完了物件／施工中／合計・1件単価・受注Total（件数・金額・1件単価）を計算して出します。毎日の受注は表で出します（曜日・件数・金額・その日までの累計、いちばん下に合計と1件単価。今日の行は黄色）。棒グラフは「グラフで見る」の中で、棒を押すとその日の件数と金額が出ます
    8. 見やすい形にするには、試作用のシートを作り直す（架空） を押してください
    9. シートの数字を変えて 読み直す を押すと、画面も変わります。読めない数字があると「読めなかったところ」に出ます
    10. 毎日更新する前提です。社長の端末で Googleとまとめて同期 を押すたびに、売上報告も読み直します。シートの最終更新の日時が出て、今日まだ更新されていないときは「今日はまだ更新されていません」と黄色で出ます（同期の結果にも「× 売上報告」と出ます）

    売上報告に数字を入れられる人（例：専務）

    1. 社長の端末の「グループ各社売上進捗報告」の中の 入力できる人 を開き、入れてもらう人にチェックを入れて 入力できる人を保存 を押す
    2. あわせて、Googleスプレッドシートで売上報告のシートを開き、右上の「共有」から、その人のGmailを「編集者」で加えてください。このシートはHUBの外で作ったので、HUBからは共有できません
    3. その人がスマホで Googleとまとめて同期 を押すと、「数字」のいちばん上に売上報告と「数字を入れる」が出ます。ホームの「今月の受注」のタイルにも「タップして数字を入れる ›」が出ます
    4. 入れられる会社は役割で決まります：全社の人（本部長）は3社、GMはGMの会社だけ、ほかの人はその人の会社だけです。名前の横に「入れられる会社」が出ます。役割を変えたときは、もう一度 入力できる人を保存 を押してください
    5. 入れた数字は、そのままシートに書きます（変えたマスだけ。会社の更新日は今日になります）。「社長の確認をした」の印は社長だけが付けられます。入力できる人を選ぶのも社長だけです
    6. 3社を入れられる人（全社の人。例：専務）は、ホームの「今月の受注」を社員に届ける役も持ちます。社長が同期できない日も、その人が同期すれば社員に新しい数字が届きます。そのために、その人を「会社の数字」のシート（会社ごとに1つ）の「編集者」にしてください（Googleドライブの「CPG HUB データ」のフォルダにある「CPG HUB_会社の数字_CP」などの「共有」で、「閲覧者」を「編集者」に変えます）。書けないときは、その人の売上進捗報告の上に「社員への今月の受注を書けなかった会社」と出ます
    7. 共有を加え忘れていると、その人の画面に「売上報告のシートを開けません。社長にシートの共有（編集者）を頼んでください」と出ます
    8. やめるときは、チェックを外して保存します（その人の次の同期で出なくなります）。シートの共有もGoogleで外してください

    この端末の控え（スマホのデータが消えたときのため）

    社長の端末で入れた案件・入金・立替・ToDoは、その端末の中にだけ保存されています。スマホの更新や「デバイスケア」などでデータが消えると戻せないので、端末ごとに控えを作ってください。

    1. 数字 → 管理（社長用）の「この端末の控え」で、この端末の名前（例：Fold8、Flip8）を入れて 控えを作る。社長のマイドライブに「CPG HUB_社長の控え_名前」ができます（だれとも共有しません）
    2. あとは Googleとまとめて同期 のたびに控えます（同期の結果に「この端末の控え」が出ます。控えがまだない端末では「まだ作っていません」と赤で出ます）。今すぐ控える でも控えられます。領収書の写真は入りません
    3. 端末ごとに別の名前にしてください（2台が同じ控えに書くと、お互いを上書きします）
    4. データが消えたときは、管理をはじめる のあと 前の控えから戻す → その端末の控えを選んで 置き換える。今の記録は端末の中の別の場所に残します
    5. 端末の記録が控えよりずっと少ないとき（消えた直後など）は、控えを上書きしません（同期の結果に出ます）

    2台目の端末で使う（スマホとPCなど）

    1. 2台目の端末でも、社長のアカウントでログインして 数字 → 管理をはじめる
    2. 1台目で作ったフォルダ「CPG HUB データ」と「CPG HUB_社員一覧」を見つけて使います。「既存の管理データを読み込みました（社員○人）」と出ればOK。新しいフォルダは作りません
    3. 「同じ名前のフォルダが○つあります」と出たときは、一番古いフォルダを使っています。社長のドライブで中身を確かめてください
    4. 「見る人用一覧」は、社長のどの端末でも同じ1つを使います（社員一覧のファイルの「HUBの設定」タブに残します）。前の版で端末ごとに別の一覧ができていたときは、いちばん新しく更新された一覧にそろえ、古い一覧には新しい一覧の場所を書きます（見る人の端末は次の同期で移ります）
    5. ほかの端末で社員を追加したり共有を外したりしたあとは、一覧を読み直す を押すと、この端末の一覧も最新になります（「社員の記録を読み込む」のときにも読み直します）
    6. 同じGmailの社員がもう一覧にあるときは、追加できません（「○○さんはすでに追加されています」と出ます）

    共有を外す（退職のときなど）

    1. 「管理（社長用）」の一覧で、その人の 共有を外す → 共有を外す → 対象の一覧を読み、一覧を確認して実行。旧共有・帰属不明は残るので、アクセスを完全に止める必要があるときは管理者が個別確認してください
    2. シートは消えずに、社長のドライブに残ります

    途中で止まったあと、もう一度実行したとき：前回、共有を付けようとして Google の不具合などで届かなかった人（その人の共有が1つも無い）には、もう一度付けます（重複しません）。共有が付いたかどうか分からないもの（共有が残っている、外す操作の結果が分からない）は、今までどおり「要確認」にして自動では変えません。

    途中で止まったとき：画面の下に「ここで止まりました」と理由が出ます。共有を変える前（「共有の一覧を読んでいます」など）で止まったときは「共有はまだ何も変えていません（外していません）」と出ます。続ける場合だけ、もう一度その人の 共有を外す から始めてください（押し直さなければ何も変わりません）。共有を変えている途中で止まったときは、止まる前に反映した分は残り、社員一覧の「共有管理履歴」に記録があります。共有の一覧は3件ずつ読み、回数制限・時間切れのときは少し待って2回まで読み直します。

    本人のカレンダーを結び付けていない人：案件の予定は全員「CPG HUB」に入れる決まりなので、その人の自分のカレンダーを「仕事用カレンダーの対応設定」で結び付けていなくても、「CPG HUB」が読めていれば、予定の画面でその人を選んだときに「未取得」は出ません（ⓘ に「CPG HUB の予定だけを出しています」と出ます）。本人のカレンダーだけに入れた予定も見たいときは、その人のカレンダーを結び付けてください。

    「CPG HUB」の予定の見え方：「CPG HUB」の予定のうち、HUBから登録した案件の予定（説明に「担当：○○」）は、その担当の人の予定として出ます（予定の画面で人を絞ったとき・札）。担当は社員一覧の氏名・表示名で照らし、1人に決まるときだけです（「黒木」のような名字だけも、同じ名字の人がいなければ決まります）。担当の行がない予定（Googleカレンダーで「CPG HUB」に直接入れた予定も）は、作成者のGmailが社員一覧と一致すればその人にします。担当が1人に決まらない予定（例：「担当：黒木」）は、担当の名前に当てはまる人の中に作成者がいればその人、いなければ誰にも割り当てません（担当とずれないように）。社長が作った予定（来社・会議など）と、作成者も一致しない予定は、今までどおり「仕事用カレンダーの対応設定」のとおりです。見る人の端末では、見てよい人の予定だけが出ます。
    「CPG HUB」の対応は設定しなくても自動です（対応設定に「CPG HUB → 複数の人が使う仕事用（自動）」と出ます）。この端末で別の対応を保存したときはそれが優先です。「Googleカレンダー連携」で「CPG HUB」のチェックを外して保存すると、自動では戻しません。

    案件の予定の登録先：社員の案件の予定は、共有カレンダー「CPG HUB」に登録します（設定で別のカレンダーを選んだ端末はそこ）。社員が「CPG HUB」に書けるよう、社員を追加したら「CPG HUB」を「予定の変更」で共有してください（上の「社員を追加する」）。

会社の動きを見る人用（全社・GM・経理・業務管理）

社長から役割を「全社」「GM」「経理」「業務管理」にしてもらった人だけが使えます。社員の記録は見るだけで、直すことはできません。経理・業務管理の人が見られるのは、担当の会社の社員だけです。業務管理の人には、ほかの人の立替・領収書は出ません。全社・GMの人はタスクリクエストを出せます（下の「GM・全社からタスクリクエストを出す」）。経理・業務管理の人は出せません。

  1. 先に、本人の記録シートをつないで最初の同期をする。新しい端末では、ホームの「初期設定」で役割を「GM・全社」にし、Googleにログイン → 本人の記録シートにつなぐ → 氏名・会社を確かめる → 最初の同期 → カレンダーの共有 → 見る人用一覧をつなぐ の順に進めます。最初の同期より前に見る人用一覧はつなげません（逆の順番だと、会社・人の選択肢から自分が外れるため）
  2. 社長から届いた「見る人用のリンク」をコピーする
  3. CPG HUB の 数字 → 「会社の動きを見る（管理者用）」に貼り付けて つなぐ（Googleの画面が出たら許可）
  4. ホームの「会社の動き」を押すと専用ページが開きます。社員の記録を読み込む を押すと、見てよい社員の同期の状況・案件・ToDo・未入金・立替が出ます。上のボタンで会社ごとに絞り込めます
  5. 読み込んだあとは、案件・ガント・ToDo の画面にも「社員の記録・見るだけ」で出ます（予定には今日以前が期限の未完了ToDoのみ）。最後に読み込んだ内容は端末に残り、開き直しても見られます（30日まで）。最新にするときは Googleとまとめて同期 を押してください。役割や共有が外れると、残した内容は消えます
  6. GMは、同じ1社だけに所属する一般社員の分だけが出ます。前の共有が残っていても、HUBには出ません
  7. ホームには、自分が出したリクエストの未完了の数（期限切れ・5日以内）が出ます

「見る人用一覧が読めていません」と出たときは、「数字」→「会社の動きを見る（管理者用）」がつながっているか確かめて、Googleとまとめて同期 を押してください。読めるまでは、仕事用カレンダーの対応設定でほかの社員を選べず、会社も自分の分しか出ません。同期の結果で「社員の記録」の行に × が出ていたら、その理由を社長に伝えてください。

GM・全社・経理・業務管理からタスクリクエストを出す

  1. ホームの「会社の動き」を押して開いたページで 社員の記録を読み込む（または Googleとまとめて同期）
  2. 「会社の動き」の「ToDo」のすぐ下の「タスクリクエストを出す」で、宛先の枠を押して出したい人にチェックを入れ（何人でも）、「内容」と「期限」を入れます。宛先の一覧に出るのは出せる相手だけです。GMは同じ1社だけの一般社員（管理者・複数会社を除く）、全社の人は全員、経理・業務管理の人は担当の会社に所属する社員に出せます（自分あては出せません。見られる人と同じ範囲です）。用途の例：業務管理は連絡事項・ToDo、経理は締め・請求・未入金・出勤表・経費精算など。社員の画面には「経理 ○○から」「業務管理 ○○から」と出ます。
  3. 経理・業務管理の人を初めて出し手にするときは、社長の端末で、その人の会社・役割を保存し直してください（担当の会社の社員の指示箱を作り、出し手として共有します）。
  4. リクエストする を押すと、チェックした人それぞれに1件ずつ出て、「○○さん：出しました」と人ごとに出ます。社員が同期するまで届きません（急ぎならLINEでも伝えてください）
  5. 「あなたが出したタスクリクエスト」に、未完了（期限切れは赤）・完了（完了日と完了メモ）・取り消しが出ます。社員が完了にして同期すると、次の読み込みで「完了」になります
  6. やめたリクエストは 取り消す → 確認で 取り消す。取り消しは完了にはなりません。取り消せるのは自分が出したものだけです（社長はどれでも取り消せます）
  7. 社員の記録シートには書き込めません（見るだけのまま）。リクエストは、社員ごとの「指示箱」に入ります

指示箱がまだありませんと出たときは、社長の端末で、その人の会社・役割をもう一度保存してもらってください（指示箱はそのときに作られます）。
