CPG HUB 管理者向けマニュアル（社長・全社・GM）

タスクリクエストの当日期限（「今日」）は赤字・太字で表示します。指示名・担当・未来日と通常ToDoの表示は変わりません。

このマニュアルは v1.49.3用　最終改訂日：2026年11月3日

v1.47.3では「数字」の自動ToDoの期限設定（目安）の説明を明確にしました。詳細は社員向け説明へ。

v1.47.2の表示改善は公開済みです。ToDoでは未完了の期限切れ〜日本時間の今日＋5日までを通常ToDoの上に小さく表示します。押すと全文・金額などが開き、再度押すと閉じます。6日以上先と期限なしは「指示一覧」で確認できます。既存の指示箱の一覧・閲覧制限・同期は変わりません。

v1.47.1では社員の指示箱受信・完了報告に対応しています。操作と未送信時の確認は社員向けの同期・リクエスト説明へ。

社員の毎日の使い方（受付・案件・ToDo・予定・ガント・領収書・同期・困ったとき）は、社員向けの使い方マニュアルにあります。改訂履歴も、社員向けのマニュアルの最後にあります（改訂履歴）。

社長用（管理）

社長のアカウントでログインしたときだけ使えます。詳しい手順は 記録を集める設定（data-setup.md） にあります。

社員を追加する

  1. 先に、Google Cloud の「対象」で、その社員をテストユーザーに追加する
  2. CPG HUB の 数字 → 一番下の「管理（社長用）」の見出しを押して開き、氏名とGmailを入れて 社員を追加
  3. その人に共有メールが届きます。「記録シートにつなぐ」をしてもらう
  4. ホームの「会社の動き」を押して開いたページで 社員の記録を読み込む を押すと、みんなの様子が見られます（今日まだ同期していない人は赤で出ます。社員は1日3回同期する決まりです。専務はいつも「黒木秀」、同じ名字の人は「黒木祐」のように名の1字を付けて区別します）
  5. 「ToDo」の欄では、社員ごとに 期限切れ（赤）→ 今日 → 今後7日 の順にToDoが出ます。期限切れがある人は名前が赤になります。8日以降と期限なしは件数だけです。「ToDoはまだ届いていません」と出る人は、その人のCPG HUBを v1.29 以降にして「Googleとまとめて同期」を押してもらうと届きます

タスクリクエストを出す

v1.47.0 から、GM（その会社の社員あて）と全社の人（全員あて）もタスクリクエストを出せます。社長の画面の「タスクリクエスト（GM・全社から）」に、出した人の表示付きで全部出て、社長はどれでも取り消せます。GM・全社の人には、社員ごとの「指示箱」（社長のドライブの「CPG HUB データ」の「CPG HUB_指示箱_氏名」）が、会社・役割の保存時に一覧で確認してから編集者で共有されます。社員の記録シートは見るだけのままです。GMを外したり入れ替えたりしても、その人が出した未完了のリクエストは残ります（社長が取り消せます）。

タスクリクエストは代表からの必ずやる依頼です。社員のToDoの画面では、期限に関係なく一番上の「タスクリクエスト」の欄に出ます。社長・全社・GMの端末のToDoの画面でも、読み込んだ社員のリクエストが一番上に、担当のバッジ付きで出ます（取り消した・完了したリクエストは出ません）。

  1. ホームの「会社の動き」を押して開いたページで 社員の記録を読み込む を押す
  2. 「ToDo」の欄で、「タスクリクエスト（代表から）」に、その社員への「リクエストの内容」と「期限」を入れて リクエストする
  3. 「○○さんが同期すると届きます。急ぎならLINEでも伝えてください」と出ます。社員が同期するまで届かないので、急ぐときはLINEでも伝えてください
  4. 社員の名前の横に「リクエスト 未完了 ○・期限切れ ○」が出ます。未完了は期限の近い順で、期限切れは赤です。社員が完了にして同期すると「最近7日の完了」に完了日と完了メモが出ます（もう一度「社員の記録を読み込む」を押すと最新になります）
  5. やめたリクエストは 取り消す → 確認で 取り消す。社員の次の同期で、社員のToDoから消えます
  6. 「社員のToDo」には、社員が自分で持っているToDo（案件の自動のToDoと手入力のToDo）が出ます

会社全体を見る（案件・ガント・予定・ToDo）

  1. ホームの「会社の動き」を押して開いたページで 社員の記録を読み込む を押す
  2. 読み込んだ社員の案件とToDoが、案件・ガント・ToDo（予定は今日以前が期限の未完了ToDoのみ）と、ホームの数字（期限切れ・今日・緊急・動いている案件・未入金）にも出ます。ホームの数字は会社全体になります
  3. 社員の分には 社員の記録・見るだけ の印が付きます。押すと詳細が見られますが、直したり消したりはできません。直すときは担当の社員に頼んでください
  4. ガントとToDoは、担当で絞り込めます
  5. 数字 の画面（月別／全期間の見積提出・受注・失注・決定率・受注額、失注の理由、種類別と、期間対象外の現在未入金）も、社員の案件を含めた会社全体の数字になります。上の 全社／CP／CPY／AT で会社ごとに絞り込め（案件の会社で分け、未設定なら担当者の所属の会社）、「担当別」の表で担当ごとの見積提出・受注・受注額・未入金が見られます。画面の上に「社員の記録（月/日 時:分 読み込み）を含めた会社全体の数字です」と出ます。「社員の記録はまだ読み込んでいません」と出ているときは、この端末で入力した分だけの数字なので、「Googleとまとめて同期」を押してください。GMの端末では、数字はGMを務める会社の分だけで、会社の絞り込みはその会社に固定です（「会社の動き」の絞り込みも同じで、GMの会社に固定です。全社の役割の人は、社長と同じく全社から選べます）
  6. 「会社の動き」の CP／CPY／AT で、会社ごとに絞り込めます。案件は案件の「会社」で分けます（会社が未設定の古い案件は、担当者の所属の会社で分けます）。同期の状況は、いつも全員分が出ます
  7. 社員がHUBからGoogleカレンダーに入れた予定は、Googleの予定として表示します。案件の進捗印は足しません。社員のToDoも、期限が今日以前のものだけ今日の欄にも出ます
  8. 最後に読み込んだ内容はこの端末に残り、アプリを開き直しても「前回の読み込み（月/日 時:分）の内容です」と出て、そのまま見られます（30日まで。ログイン情報は残しません）。最新にするときは Googleとまとめて同期 を押すと、カレンダーに続けて社員の記録も読み込みます（結果に「社員の記録：○人・案件○件」の行が出ます）
  9. 社員の同期が古いと、古いままの内容が出ます（「同期の状況」で最終同期を確かめてください）。v1.29 以前で同期した社員の案件は、見積提出・保留などの日付が届いていないので、ガントの帯が一部だけになります

会社・役割（全社・GM）を決める

  1. 数字 → 「管理（社長用）」で、社員を追加するときに「会社（複数可）」「役割」「GMを務める会社」を選ぶ。あとから変えるときは、その人の 会社・役割 → 選んで 保存する
  2. 役割：社員＝自分の記録だけ。GM＝同じ1社だけに所属する一般社員の記録を見る（複数会社・全社・GMは除く）。全社＝全員の記録を見る（例：専務）。全社の人がある会社のGMも務めるときは、役割を「全社」にして「GMを務める会社」を選びます（見る範囲は全社が優先です）
  3. GMは各社1人です。同じ会社に2人目を選ぶと「○○のGMはすでに○○さんです。入れ替えますか？」と出ます。入れ替える を押すと、前の人はGMから外れ（役割がGMなら「社員」に戻ります）、共有変更の一覧を確認します。旧共有・帰属不明の共有は残して要確認にします
  4. 保存操作ではまず共有一覧を確認し、確認後に見る人へ、見てよい社員のシートを 閲覧者 で共有します。役割を外したり会社を変えたりすると、当機能の付与記録を確認できた共有だけ解除します。旧共有などは残して要確認にします（役割変更では本人の編集者の共有は維持します）
  5. 見る人がいると「見る人用のリンク」が出ます。リンクをコピー して、見る人に送ってください（LINEなど）

2台目の端末で使う（スマホとPCなど）

  1. 2台目の端末でも、社長のアカウントでログインして 数字 → 管理をはじめる
  2. 1台目で作ったフォルダ「CPG HUB データ」と「CPG HUB_社員一覧」を見つけて使います。「既存の管理データを読み込みました（社員○人）」と出ればOK。新しいフォルダは作りません
  3. 「同じ名前のフォルダが○つあります」と出たときは、一番古いフォルダを使っています。社長のドライブで中身を確かめてください
  4. ほかの端末で社員を追加したり共有を外したりしたあとは、一覧を読み直す を押すと、この端末の一覧も最新になります（「社員の記録を読み込む」のときにも読み直します）
  5. 同じGmailの社員がもう一覧にあるときは、追加できません（「○○さんはすでに追加されています」と出ます）

共有を外す（退職のときなど）

  1. 「管理（社長用）」の一覧で、その人の 共有を外す → 共有を外す → 対象の一覧を読み、一覧を確認して実行。旧共有・帰属不明は残るので、アクセスを完全に止める必要があるときは管理者が個別確認してください
  2. シートは消えずに、社長のドライブに残ります

画面の上の部分（社長・全社・GM）

どのタブも、いちばん上は会社・人の細い1行です。押すと選べます。注意があるときだけ赤い札（期限切れToDo・緊急・失注日なし・未読込の人数）が出て、押すとその一覧が開きます。説明は「ⓘ」を押したときだけ出ます。大きな「Googleとまとめて同期」はホームだけで、ほかのタブは小さな「日時 ↻」で同期します。会社の動きの「記録を読み込む」は見出しの下、「一覧を読み直す」は「ⓘ」の中です。

会社の動きを見る人用（全社・GM）

社長から役割を「全社」か「GM」にしてもらった人だけが使えます。社員の記録は見るだけで、直すことはできません。タスクリクエストは出せます（v1.47.0 から。下の「GM・全社からタスクリクエストを出す」）。

  1. 先に、本人の記録シートをつないで最初の同期をする。新しい端末では、ホームの「初期設定」で役割を「GM・全社」にし、①Googleにログイン → ②本人の記録シートにつなぐ → ③氏名・会社を確かめる → ④最初の同期 → ⑤見る人用一覧をつなぐ の順に進めます。④より前に見る人用一覧はつなげません（逆の順番だと、会社・人の選択肢から自分が外れるため）
  2. 社長から届いた「見る人用のリンク」をコピーする
  3. CPG HUB の 数字 → 「会社の動きを見る（管理者用）」に貼り付けて つなぐ（Googleの画面が出たら許可）
  4. ホームの「会社の動き」を押すと専用ページが開きます。社員の記録を読み込む を押すと、見てよい社員の同期の状況・案件・ToDo・未入金・立替が出ます。上のボタンで会社ごとに絞り込めます
  5. 読み込んだあとは、案件・ガント・ToDo の画面にも「社員の記録・見るだけ」で出ます（予定には今日以前が期限の未完了ToDoのみ）。最後に読み込んだ内容は端末に残り、開き直しても見られます（30日まで）。最新にするときは Googleとまとめて同期 を押してください。役割や共有が外れると、残した内容は消えます
  6. GMは、同じ1社だけに所属する一般社員の分だけが出ます。旧共有が残っている場合でもHUBでは対象外です

GM・全社からタスクリクエストを出す

  1. ホームの「会社の動き」を押して開いたページで 社員の記録を読み込む（または Googleとまとめて同期）
  2. 出せる相手の欄に「リクエストの内容」と「期限」が出ます。GMは同じ1社だけの一般社員（管理者・複数会社を除く）、全社の人は全員に出せます（自分あては出せません）。入れて リクエストする
  3. 「○○さんが v1.47.1 以降の CPG HUB で同期すると届きます。急ぎならLINEでも伝えてください」と出ます。社員が同期するまで届きません
  4. 「あなたが出したタスクリクエスト」に、未完了（期限切れは赤）・完了（完了日と完了メモ）・取り消しが出ます。社員が完了にして同期すると、次の読み込みで「完了」になります
  5. やめたリクエストは 取り消す → 確認で 取り消す。取り消しは完了にはなりません。取り消せるのは自分が出したものだけです（社長はどれでも取り消せます）
  6. 社員の記録シートには書き込めません（見るだけのまま）。リクエストは、社員ごとの「指示箱」に入ります

指示箱がまだありませんと出たときは、社長の端末で、その人の会社・役割をもう一度保存してもらってください（指示箱はそのときに作られます）。

v1.47.5（2026年10月31日）数字の集計

以下はv1.47.5での変更記録です。v1.48.3からは「今月」に限らず、上部の月別／全期間で選んだ期間を使います。

失注にした案件は、受注日が残っていても受注には数えません。ただし、実際に受注したあとの取消は、これまでどおり元の受注実績に残します。今月の失注件数・担当別・種類別・理由・決定率には、今月の失注日がある案件だけを数えます。失注日が空の案件は集計に入れず、「失注日が未入力の案件」として別に件数を出します。日付を自動で埋めることはありません。種類別の「見積提出」は、担当別と同じく今月提出した件数です。日付の食い違いには案件画面で注意を出しますが、保存は止めません。

日付や、誤った受注・取消の記録を直す

自分の端末で案件を開き、「受注日・失注日・理由を直す」を押します。受注日を消すときは空欄にし、失注日・理由を確認して「内容を確認して保存」を押してください。確認画面に出る案件と変更前・変更後を読み、よければ確定します。「やめる」や確認のキャンセルでは変更しません。誤って受注してから取り消した場合は「失注（受注していなかった）に直す」を使い、失注日と理由を入れます。確定すると受注日と現在の取消情報を外し、通常の失注として数えます。本当に受注した後の取消には使わないでください。どちらの操作も元の受注日・失注日・理由・取消情報を「受注・失注の訂正履歴」に残します。履歴はこの端末とJSONバックアップに残り、共有シートには現在の値だけが届きます。共有社員の記録や引渡・施工以降の案件は、この操作で直せません。保存結果を確認できないときは再保存せず、再読み込みして最新の記録を確認してください。

v1.47.6（2026年10月31日）失注理由の共有

失注の理由（価格・他社に決定・時期が合わない・連絡なし・その他）が社員の同期で共有され、社長・全社・GMの「数字」に反映されます。理由を入力し直す必要はありません。空欄や知らない値を「その他」に置き換えることはありません。

使うすべての社員端末と社長・全社・GM端末で古いCPG HUBのタブを閉じ、開き直してv1.47.6以降を確認してください。データ削除や再インストールは不要です。まず社員が「Googleとまとめて同期」、次に社長側も同期して社員の記録を読み込み直します。旧版の社員端末や開いたままの旧タブで同期すると、共有の失注理由列が消えます。その場合は理由を保持している社員の新版端末から再同期し、社長側で再読込みします。社員の端末の元の理由は今回の修正では変更しません。

v1.47.7（2026年10月31日）ホームの同期結果

ホームで自分の端末の同期が最後まで全て成功すると「✅ 同期済み 月/日 時:分」の1行になります。押すと詳しい結果が開き、もう一度押すと閉じます。時刻は日本時間です。エラー・一部失敗・同期途中の終了・今日まだ同期していない警告・未送信の完了報告・対応が必要な注意は隠しません。v1.47.7では同期ボタンの位置と大きさを維持しました（v1.48.0ではホームの順番を変更）。予定や設定画面の詳しい同期結果もそのまま表示します。社長・全社・GMでは、社員の今日未同期や記録の読込失敗だけでは自分の結果を開いたままにしません。社員ごとの注意は「会社の動き」に残り、社員の記録の読込失敗行も折りたたみの外に表示します。自分の端末のエラー・未完了・今日未同期・未送信報告・保存の不確実は、引き続き折りたたみません。

v1.48.0（2026年11月1日）ホームのまとめタイル

ホームは「今日のまとめ」のタイル、タスクリクエスト件数、同期ボタンと結果、会社の動きのタイルの順です。0件でも表示します。期限切れ・緊急・入金遅れ・同期の注意は赤で示します。各タイルを押すと詳しいページへ移動します。

「対応中の緊急」は案件を緊急対応だけに絞り、受付からの経過時間を確認できます。「動いている案件」は案件一覧、「未入金」は数字の未入金、「立替 未提出」「提出済・未精算」は領収書を開きます。「Access引渡待ち」は受注済みで、取消記録がなく、仕事番号が空欄の案件です。1件以上は赤く表示し、押すと同じ条件の案件だけを開きます。一覧の「Access引渡待ちだけ」を外すと絞り込みを解除できます。0件でもタイルは残ります。「今日までのToDo」の件数は従来どおり当日期限分です。リクエストや各集計の計算は変えません。

社長・全社・GMには「会社の動き」のタイルが出ます。社員数、今日未同期・読めなかった社員の人数を確認し、押すと会社の動きのページを開きます。「ホームへ戻る」で戻ります。下のメニューには追加しません。会社選択・GMの会社範囲は従来どおりです。社員別の立替表は領収書ページの先頭へ移しました。会社の動きで選んだ会社範囲（GMは担当会社）を引き継ぎます。

同期の成功結果の開閉はv1.47.7と同じです。自分のエラー・未完了・今日未同期・未送信報告・保存未確認はホームに残ります。会社側の注意で自分の成功結果の折りたたみを止めません。注意が多い場合はホームを下へスクロールしてください。

v1.48.1（2026年11月1日）自分が出したリクエスト

v1.49.0（2026年11月2日）共通の会社・人選択

ホーム・案件・ToDo・数字・ガント・指示一覧・領収書・会社の動きは、共通の会社・人のドロップダウンで同じ対象を選びます。人は案件と通常ToDoでは担当、リクエストでは宛先、領収書では所有者です。初めは自分。会社と人を選ぶと画面移動・再読込後も引き継ぎます。会社未設定の案件・領収書は所属会社から推測せず「会社未設定」で確認します。案件に結び付かないToDoとリクエストの会社は、根拠のある担当・宛先の所属によります。
